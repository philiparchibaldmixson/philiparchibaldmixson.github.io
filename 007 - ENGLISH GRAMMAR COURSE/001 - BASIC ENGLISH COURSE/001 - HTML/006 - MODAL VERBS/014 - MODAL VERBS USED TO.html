📘 MODAL VERB: USED TO 📘

Talking About Past Habits and States

🌟 What Does "Used To" Mean?

USED TO is a modal-like expression used to describe past habits or situations that are no longer true. It helps us talk about things we did regularly in the past or states that changed.

  • Used to + base verb → Describes past routines or facts.
  • Didn’t use to → Negative form.
  • Did you use to...? → Question form.

📋 Structure with "Used To"

Form Structure Example
Affirmative Subject + used to + base verb I used to play soccer.
Negative Subject + didn’t use to + base verb She didn’t use to like coffee.
Question Did + subject + use to + base verb? Did you use to live here?

💡 Quick Tip

Use used to only for the past. For present habits, use usually or the present simple.

🎯 Common Uses of "Used To"

1. Past Habits
Things you did regularly in the past

• I used to ride my bike every day.
• He used to play video games after school.
• We used to go to the beach every summer.
• They used to eat dinner at 6 PM.

2. Past States
Situations that were true before but changed

• She used to live in São Paulo.
• I used to be shy.
• We used to have a dog.
• He used to work at a bank.

📝 More Examples

✅ Affirmative

• I used to watch cartoons.
• She used to study French.
• We used to play outside.
• They used to live in Canada.

🚫 Negative

• I didn’t use to like vegetables.
• He didn’t use to speak English.
• We didn’t use to travel much.
• They didn’t use to eat sushi.

❓ Questions

• Did you use to play guitar?
• Did she use to live here?
• Did they use to go camping?
• What did you use to do on weekends?

📌 Related Expressions

Would
"We would go fishing every summer." (past habit)
Usually
"I usually wake up early." (present habit)
Be used to
"I’m used to waking up early." (accustomed to)

🔄 Real-Life Sentences

Using "Used To" in Context

• I used to live in Itamaraju.
• She didn’t use to like coffee.
• Did you use to play piano?
• We used to visit our grandparents every weekend.

⚠️ Common Mistakes to Avoid

❌ Wrong → ✅ Correct

❌ I use to play soccer.
✅ I used to play soccer.

❌ Did you used to live here?
✅ Did you use to live here?

❌ She didn’t used to like tea.
✅ She didn’t use to like tea.

❌ We use to go camping.
✅ We used to go camping.
