📦 Passives – Verbs with Two Objects

Some verbs can take two objects: a direct object (thing) and an indirect object (person). In passive voice, either object can become the subject of the sentence.

✅ Common Verbs with Two Objects

Examples include: give, send, show, offer, tell, lend, pay, promise, teach, write.

🧠 Structure

Active: Subject + verb + indirect object + direct object

Passive 1: Indirect object + be + past participle + by + agent

Passive 2: Direct object + be + past participle + to/for + indirect object

Examples:
Active:
They gave her a gift.
Passive 1 (person as subject):
She was given a gift.
Passive 2 (thing as subject):
A gift was given to her.
