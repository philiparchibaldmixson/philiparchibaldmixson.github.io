🎯 Passives – Reasons for Using Passives

We use the passive voice when we want to focus on the action or the receiver of the action, rather than the person or thing doing it. This is common in formal writing, scientific reports, and when the agent is unknown or irrelevant.

✅ Common Reasons for Using the Passive

  • When the agent is unknown: The window was broken.
  • When the agent is obvious or not important: The thief was arrested.
  • To be more formal or impersonal: A decision was made.
  • To focus on the result or receiver: The documents were signed by the director.
  • In scientific or technical writing: The experiment was conducted in a lab.
Examples:
Unknown agent:
The cake was eaten before I arrived.
Impersonal tone:
The rules were updated last week.
Focus on receiver:
The award was given to the best student.
