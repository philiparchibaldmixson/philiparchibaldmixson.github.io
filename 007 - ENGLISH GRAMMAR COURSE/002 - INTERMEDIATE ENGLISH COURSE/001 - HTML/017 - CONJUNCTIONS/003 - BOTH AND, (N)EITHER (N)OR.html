🔗 Conjunctions – Both ... And / (N)either ... (N)or

These paired conjunctions are used to connect two elements in a sentence. They help express inclusion or exclusion clearly and are common in both spoken and written English.

✅ Both ... And

  • Used to show that two things are true or included
  • Structure: both + element A + and + element B
  • Example: Both John and Sarah are coming.

✅ Either ... Or

  • Used to show a choice between two options
  • Structure: either + element A + or + element B
  • Example: You can either stay or leave.

✅ Neither ... Nor

  • Used to show that two things are not true or not included
  • Structure: neither + element A + nor + element B
  • Example: Neither the manager nor the assistant was available.
Examples:
Both ... And:
Both the teacher and the students enjoyed the trip.
Either ... Or:
either call me or send a message.
Neither ... Nor:
Neither the lights nor the heater is working.
