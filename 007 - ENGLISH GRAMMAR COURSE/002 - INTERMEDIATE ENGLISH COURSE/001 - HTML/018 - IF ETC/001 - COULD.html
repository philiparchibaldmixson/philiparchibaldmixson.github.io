🚴 Conditionals – Could = Would Be Able To

In conditional sentences, we often use could to mean would be able to. This is common in second conditionals, which describe unreal or hypothetical situations.

✅ Structure

  • If + past simple, could + base verb
  • Example: We could go cycling if it didn’t rain.
  • Could expresses possibility or ability in a hypothetical situation

✅ Meaning

  • Could = would be able to
  • Used when something is possible but not certain or real
  • Example: If I had a bike, I could join you. (I don’t have a bike now)
Examples:
Hypothetical:
We could go cycling if the weather were better.
Ability:
I could help if I had more time.
Opportunity:
She could travel more if she earned more money.
Permission:
They could stay longer if they asked.
