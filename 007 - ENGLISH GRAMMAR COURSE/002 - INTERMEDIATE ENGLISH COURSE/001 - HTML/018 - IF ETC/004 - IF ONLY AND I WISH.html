💭 If Only and I Wish – Unreal Tenses

If only and I wish are used to express regret or desire for something that is not true now or didn’t happen in the past. They are followed by verb forms that reflect unreal or hypothetical situations.

✅ Present Unreal (wish for change now)

  • If only / I wish + past simple
  • Example: If only I knew the answer. (I don’t know it now)
  • Used to express regret or desire about the present

✅ Past Unreal (wish for change in the past)

  • If only / I wish + past perfect
  • Example: I wish I had studied more. (I didn’t study)
  • Used to express regret about something that didn’t happen

✅ Future Unreal (unlikely future)

  • If only / I wish + would + base verb
  • Example: I wish you would listen.
  • Used to express annoyance or hope for change
Examples:
Present unreal:
If only I knew what to say. (But I don’t)
Past unreal:
I wish I had gone to the party. (But I didn’t)
Future unreal:
I wish you would stop shouting. (You keep shouting)
Present regret:
If only I spoke French. (I don’t speak it)

  • If only I (were / had been) taller. → Present unreal
  • I wish I (had studied / studied) harder. → Past unreal
