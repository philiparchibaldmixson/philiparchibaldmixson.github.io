Advanced Grammar – Order of Adjectives

Understanding the Order of Adjectives

When multiple adjectives are used before a noun, they usually follow a specific order. Native speakers follow this order naturally, but it can be tricky for learners. The general order is:

Opinion → Size → Age → Shape → Color → Origin → Material → Purpose + Noun

Not all categories are always used, but when they are, this is the preferred sequence.

Examples and Usage

Correct Order

A beautiful small old round red Italian leather handbag
An amazing large new rectangular blue Japanese wooden table

Incorrect Order

✗ A leather Italian red round old small beautiful handbag
✗ A wooden Japanese blue rectangular new large amazing table
Tip: You don’t always need all categories. Use only the adjectives that are relevant, but keep them in the correct order.
