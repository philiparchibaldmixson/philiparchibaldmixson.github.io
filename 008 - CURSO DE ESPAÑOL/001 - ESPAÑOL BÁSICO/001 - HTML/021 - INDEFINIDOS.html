🌫️ Indefinidos: Uno, Alguno, Ninguno 🌫️

Uso y apócopes en español

🌟 ¿Qué son los Indefinidos?

Los indefinidos uno, alguno, ninguno se usan para referirse a personas o cosas no específicas. Cambian según el género y número del sustantivo que acompañan.

Ejemplo: alguno de ellos, ninguna respuesta, uno solo.

✂️ ¿Qué es un Apócope?

Un apócope es la forma abreviada de una palabra. En español, uno, alguno, ninguno se apocopan delante de sustantivos masculinos singulares:

  • uno → un
  • alguno → algún
  • ninguno → ningún

💡 Consejo

La apócope solo ocurre antes de sustantivos masculinos singulares. Ejemplo: ningún problema.

📌 Ejemplos con y sin Apócope

Un libro
Uno es mío
(apócope / completo)
Ejemplo: Tengo un libro / Tengo uno
Algún amigo
Alguno vendrá
(apócope / completo)
Ejemplo: Algún amigo llamó / Alguno llamó
Ningún caso
Ninguno fue grave
(apócope / completo)
Ejemplo: No hubo ningún caso / No hubo ninguno

🎯 Consejos para Aprender

  • Usa la forma apocopada delante de sustantivos masculinos singulares
  • Usa la forma completa cuando el sustantivo no está presente
  • Observa el contexto para elegir entre afirmación, negación o cantidad
  • Haz listas de ejemplos con y sin apócope
