✍️ Acentuación: Acento Diacrítico ✍️

Distingue palabras que se escriben igual pero tienen significados diferentes

🌟 ¿Qué es el Acento Diacrítico?

El acento diacrítico se usa para diferenciar palabras que se escriben igual pero tienen significados o funciones distintas. Solo algunas palabras monosílabas llevan tilde para marcar esta diferencia.

Ejemplo: tú (pronombre) vs tu (posesivo)

📌 Ejemplos Comunes

Tú
Tu
(pronombre / posesivo)
Ejemplo: Tú eres mi amigo / Tu casa es bonita
Él
El
(pronombre / artículo)
Ejemplo: Él canta bien / El perro duerme
Mí
Mi
(pronombre / posesivo)
Ejemplo: Para mí / Mi mochila
Sí
Si
(afirmación / condicional)
Ejemplo: Sí, quiero / Si vienes, te espero
Té
Te
(bebida / pronombre)
Ejemplo: Quiero té / Te llamo luego
Sé
Se
(verbo / pronombre)
Ejemplo: Sé amable / Se fue temprano

🧠 ¿Cuándo se usa?

El acento diacrítico se usa solo en casos específicos para evitar confusión entre palabras que se pronuncian igual pero tienen funciones distintas.

  • Se aplica a monosílabos que normalmente no llevan tilde
  • La tilde no indica pronunciación, sino función gramatical
  • Algunas palabras como solo y este ya no llevan tilde según la norma actual, salvo casos de ambigüedad

💡 Consejo

Piensa en el significado de la palabra: ¿es pronombre, artículo, posesivo, verbo? Eso te guía.

📝 Práctica

🔍 Elige la forma correcta

1. ¿Es para mi / mí?
2. El / él juega fútbol
3. ¿Quieres te / té?
4. Se / sé valiente
5. Tu / tú mochila está aquí

🎯 Consejos para Aprender

  • Haz listas de pares con y sin tilde
  • Identifica la función de cada palabra en la oración
  • Practica con frases reales y ejercicios de contexto
  • Consulta la norma actual de la RAE para casos especiales
