✍️ Acentuación: Interrogativos, Exclamativos y Hiato ✍️

Uso obligatorio de la tilde en contextos especiales

🌟 ¿Qué son los Pronombres Interrogativos y Exclamativos?

Son palabras que se usan para preguntar o exclamar. Siempre llevan tilde cuando tienen función interrogativa o exclamativa, incluso dentro de una oración.

Ejemplos: qué, quién, cómo, cuándo, dónde, cuánto, cuál

📌 Ejemplos con Tilde

¿Qué?
¡Qué!
(interrogación / exclamación)
Ejemplo: ¿Qué quieres? / ¡Qué sorpresa!
¿Quién?
¡Quién!
(persona)
Ejemplo: ¿Quién vino? / ¡Quién lo diría!
¿Cómo?
¡Cómo!
(modo)
Ejemplo: ¿Cómo estás? / ¡Cómo me alegro!
¿Cuándo?
¡Cuándo!
(tiempo)
Ejemplo: ¿Cuándo llegas? / ¡Cuándo será!
¿Dónde?
¡Dónde!
(lugar)
Ejemplo: ¿Dónde vives? / ¡Dónde estará!

🧠 ¿Qué es el Hiato?

El hiato ocurre cuando dos vocales que normalmente formarían diptongo se separan en sílabas distintas. Si una vocal cerrada (i, u) es tónica y está junto a una abierta (a, e, o), lleva tilde para marcar el hiato.

  • María → Ma-rí-a
  • país → pa-ís
  • río → rí-o
  • oído → o-í-do

💡 Consejo

La tilde en el hiato rompe el diptongo y obliga a separar las vocales en sílabas distintas.

📝 Práctica

🔍 Coloca la tilde donde corresponda

1. Como / Cómo
2. Quien / Quién
3. Pais / País
4. Rio / Río
5. Que / Qué

🎯 Consejos para Aprender

  • Identifica si la palabra está en una pregunta o exclamación
  • Recuerda que el hiato ocurre cuando la vocal cerrada es tónica
  • Practica con frases interrogativas y exclamativas reales
  • Haz listas de palabras con hiato y sus sílabas separadas
