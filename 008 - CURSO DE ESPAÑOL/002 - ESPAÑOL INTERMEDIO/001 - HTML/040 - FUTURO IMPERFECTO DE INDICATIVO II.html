🔮 Futuro Imperfecto de Indicativo 🔮

Verbos Irregulares

🌟 ¿Qué tienen de especial?

En el futuro imperfecto, algunos verbos presentan cambios en la raíz antes de añadir las terminaciones regulares (-é, -ás, -á, -emos, -éis, -án). Estas formas deben memorizarse.

Ejemplo: tener → tendré, decir → diré

📌 Verbos con raíz modificada

Tener → tendr-
Salir → saldr-
yo tendré / saldré
  • tú tendrás / saldrás
  • él tendrá / saldrá
  • nosotros tendremos / saldremos
  • vosotros tendréis / saldréis
  • ellos tendrán / saldrán
Poner → pondr-
Venir → vendr-
yo pondré / vendré
  • tú pondrás / vendrás
  • él pondrá / vendrá
  • nosotros pondremos / vendremos
  • vosotros pondréis / vendréis
  • ellos pondrán / vendrán

📌 Verbos con raíz reducida

Decir → dir-
Hacer → har-
yo diré / haré
  • tú dirás / harás
  • él dirá / hará
  • nosotros diremos / haremos
  • vosotros diréis / haréis
  • ellos dirán / harán
Poder → podr-
Saber → sabr-
yo podré / sabré
  • tú podrás / sabrás
  • él podrá / sabrá
  • nosotros podremos / sabremos
  • vosotros podréis / sabréis
  • ellos podrán / sabrán

🧠 ¿Cuándo se usa?

  • Para expresar acciones futuras: Haré la tarea mañana
  • Para hacer promesas o predicciones: Vendrás a la fiesta
  • Para expresar suposiciones en el presente: Estará en casa ahora

💡 Consejo

Aprende las raíces irregulares y añade las terminaciones regulares del futuro.

📝 Práctica

🔍 Conjuga los verbos en futuro

1. Yo ______ (tener) tiempo mañana
2. Tú ______ (hacer) la presentación
3. Ella ______ (venir) a las ocho
4. Nosotros ______ (decir) la verdad
5. Ellos ______ (poder) viajar el viernes

🎯 Consejos para Aprender

  • Haz una lista de raíces irregulares
  • Practica con frases reales y planes futuros
  • Escucha cómo se usan en canciones y diálogos
  • Combina verbos regulares e irregulares en tus ejercicios
