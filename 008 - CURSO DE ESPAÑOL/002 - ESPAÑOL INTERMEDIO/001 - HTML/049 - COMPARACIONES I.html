⚖️ Grados del Adjetivo: Comparaciones ⚖️

Cómo expresar la superioridad, inferioridad e igualdad

1️⃣ Grado Comparativo

El grado comparativo sirve para contrastar dos elementos (personas, cosas o ideas) respecto a una cualidad (el adjetivo).

Estructura de la Comparación:

Sujeto + Verbo + FÓRMULA + Adjetivo + Nexo + Elemento Comparado

a. Superioridad

Fórmula: MÁS + Adjetivo + QUE

Ej: *Mi coche es **más rápido que** el tuyo.*

b. Inferioridad

Fórmula: MENOS + Adjetivo + QUE

Ej: *Tu casa es **menos luminosa que** la de Juan.*

c. Igualdad

Fórmula: TAN + Adjetivo + COMO

Ej: *El examen fue **tan fácil como** la práctica.*

2️⃣ Comparativos Irregulares

Los adjetivos **bueno**, **malo**, **grande** y **pequeño** tienen formas de comparativo y superlativo heredadas del latín que son más comunes:

Adjetivo Comparativo de Superioridad Equivalente (*Más que*)
Bueno **Mejor** *Más bueno que* (posible, pero menos formal)
Malo **Peor** *Más malo que* (posible, pero menos formal)
Grande (Edad/Calidad) **Mayor** *Más grande que* (solo para tamaño)
Pequeño (Edad/Calidad) **Menor** *Más pequeño que* (solo para tamaño)

**Ejemplos:** *Mi hermano es **mayor que** yo* (edad). *Este vino es **mejor que** el otro* (calidad).

3️⃣ Grado Superlativo

El superlativo expresa el grado máximo de una cualidad dentro de un grupo (Superlativo Relativo) o simplemente una cualidad muy alta (Superlativo Absoluto).

a. Superlativo Relativo

Indica el más alto o más bajo dentro de un conjunto. Se mantiene la estructura de comparación:

  • **Estructura:** Artículo (El/La/Los/Las) + **Más/Menos** + Adjetivo + **De** + Grupo
  • **Ejemplo Superioridad:** *Este es **el coche más rápido de** la carrera.*
  • **Ejemplo Inferioridad:** *Esa es **la película menos interesante de** la década.*

b. Superlativo Absoluto (Absolutivo)

Expresa la cualidad en su máxima intensidad, sin compararla con ningún grupo. Se forma con sufijos o adverbios:

  • **Sufijo -ísimo/a:** *Ese libro es **carísimo**.* (*Fuerte* → **Fortísimo**)
  • **Adverbio:** *Esa casa es **muy grande**.*

🧠 Superlativos Irregulares (Absolutos)

Algunos adjetivos tienen formas históricas y menos obvias de superlativo absoluto. Aunque son formales, es útil conocerlas:

  • **Antiguo** → **Antiquísimo**
  • **Fiel** → **Fidelísimo**
  • **Pobre** → **Paupérrimo** (más común *pobrísimo*)
  • **Célebre** → **Celebérrimo**

¡Las comparaciones son la sal de las descripciones!

Usa **más que** y **menos que** para los grados sencillos, y **tan como** para la igualdad.
