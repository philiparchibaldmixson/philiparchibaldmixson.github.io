🤝 Comparación de Igualdad 🤝

Expresando que dos elementos tienen la misma cualidad o cantidad

🌟 La Base: Tres Tipos de Igualdad

En español, la igualdad se expresa de tres maneras principales, dependiendo de la parte de la oración que se compare (adjetivo, sustantivo o verbo).

Las Fórmulas Fundamentales:

1. Igualdad de Cualidad: **TAN... COMO** (con adjetivos y adverbios)

2. Igualdad de Cantidad: **TANTO... COMO** (con sustantivos)

3. Igualdad de Acción: **TANTO COMO** (con verbos)

1️⃣ Igualdad con Adjetivos o Adverbios (TAN... COMO)

Se utiliza para comparar una **cualidad** o la **manera** en que se realiza una acción.

Estructura:

Sujeto 1 + Verbo + **TAN** + Adjetivo / Adverbio + **COMO** + Sujeto 2

Ejemplos con Adjetivos:

  • *Mi coche es **tan viejo como** el de mi tío.* (Cualidad: *viejo*)
  • *La sopa está **tan caliente como** el café.* (Cualidad: *caliente*)

Ejemplos con Adverbios:

  • *Ella canta **tan bien como** una profesional.* (Adverbio: *bien*)
  • *Él corre **tan rápido como** un velocista.* (Adverbio: *rápido*)

2️⃣ Igualdad con Sustantivos (TANTO... COMO)

Se utiliza para comparar una **cantidad** de algo (sustantivo). **TANTO** concuerda en género y número con el sustantivo al que acompaña.

Estructura:

Sujeto 1 + Verbo + **TANTO(A/OS/AS)** + Sustantivo + **COMO** + Sujeto 2

  • **Masculino Singular:** *Yo tengo **tanto** dinero **como** tú.*
  • **Femenino Singular:** *Ella tiene **tanta** paciencia **como** su madre.*
  • **Masculino Plural:** *Vemos **tantos** errores **como** aciertos.*
  • **Femenino Plural:** *Hay **tantas** personas **como** sillas.*

3️⃣ Igualdad con Verbos (TANTO COMO)

Se utiliza cuando se compara la **frecuencia o intensidad de una acción** (un verbo). **TANTO** en este caso funciona como adverbio y es **invariable** (no tiene género ni número).

Estructura:

Sujeto 1 + Verbo 1 + **TANTO** + **COMO** + Sujeto 2 + Verbo 2 (o pronombre)

  • *Mi jefe trabaja **tanto como** yo.* (Comparando la acción de trabajar)
  • *Ellos disfrutaron **tanto como** nosotros.*
  • *Estudié **tanto como** mi compañero.*

🎯 Resumen y Consejos

  • **TAN... COMO** (Cualidades): ¡Recuerda, **TAN** es invariable!
  • **TANTO... COMO** (Cantidades): ¡Recuerda, **TANTO** concuerda con el sustantivo!
  • **Verbos:** Usa **TANTO** (invariable) después del verbo.

¡La igualdad es clave para equilibrar tus frases!

Practica las tres fórmulas para dominar las comparaciones.
