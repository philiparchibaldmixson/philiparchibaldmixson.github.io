🧭 Preposiciones Clave de Transcurso 🧭

A, En, Para, Por: Distintos usos de lugar y tiempo

🌟 Transcurso y Propósito

Estas cuatro preposiciones son esenciales, ya que cubren el destino (**A**), la ubicación (**EN**), la finalidad (**PARA**) y la causa/vía (**POR**).

Reglas Mnemotécnicas:

**A:** Destination / Time Limit

**EN:** Location / Time Period

**PARA:** Purpose / Deadline (Finalidad / Fecha Límite)

**POR:** Cause / Means / Duration (Causa / Medio / Duración)

1️⃣ Preposición A

Uso de Destino / Dirección

  • *Voy **a** la oficina.* (Meta final).
  • *El regalo es **a** María.* (Destinatario, aunque *para* es más común).

Uso Temporal (Hora / Límite)

  • *La reunión es **a** las diez.* (Hora precisa).
  • *De lunes **a** viernes.* (Límite final del periodo).

2️⃣ Preposición EN

Uso de Ubicación (Lugar Estático)

  • *Estoy **en** casa.* (Lugar dentro de).
  • *El libro está **en** la mesa.* (Lugar sobre).

Uso Temporal (Periodo)

  • *Viajaremos **en** verano.* (Periodo de tiempo).
  • *Lo hice **en** cinco minutos.* (Duración total requerida).

3️⃣ Preposición PARA

Uso de Finalidad / Objetivo

  • *Estudio **para** aprobar el examen.* (Propósito).
  • *Necesito dinero **para** el viaje.* (Uso, destino).

Uso de Destinatario / Fecha Límite

  • *Este pastel es **para** ti.* (Destinatario).
  • *El informe debe estar listo **para** mañana.* (Fecha límite o plazo).

4️⃣ Preposición POR

Es la más compleja, cubriendo causa, medio y movimiento a través.

Uso de Causa / Motivo / Intercambio

  • *Lo hice **por** amor.* (Motivo, razón).
  • *Te cambio mi lápiz **por** tu goma.* (Intercambio).
  • *La calle fue cerrada **por** la lluvia.* (Causa).

Uso de Medio / Vía / Duración

  • *Viajamos **por** avión.* (Medio de transporte).
  • *Paseamos **por** el parque.* (Movimiento a través de).
  • *Estudió **por** tres horas.* (Duración aproximada o total).

¡Practica la diferencia entre PARA y POR!

Recuerda: **PARA** es la meta, **POR** es el camino o la causa.
