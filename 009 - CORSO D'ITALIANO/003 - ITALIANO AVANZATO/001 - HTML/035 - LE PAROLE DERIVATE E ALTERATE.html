📚 Che Cosa Sono le Parole Derivate?

🔨 Le parole derivate si formano aggiungendo PREFISSI o SUFFISSI a una parola base!

Le parole derivate nascono quando prendiamo una parola semplice (la radice) e ci aggiungiamo dei morfemi derivazionali (prefissi o suffissi) che ne modificano il significato!

🎯 Tipi di Parole Derivate:

PREFISSAZIONE
⬅️ Prefisso + Radice
SUFFISSAZIONE
➡️ Radice + Suffisso
PARASINTESI
↔️ Prefisso + Radice + Suffisso

📋 Tabella dei Prefissi Comuni:

PREFISSO SIGNIFICATO ESEMPIO
IN-, IM-, IL-, IR- Negazione (NON) incredibile, impossibile, illegale, irrazionale
RI- Di nuovo, ripetizione rifare, rileggere, ricominciare
PRE- Prima, anteriorità preavviso, prenotare, prevedere
POST- Dopo, posteriorità posticipare, postdatare, postumo
ANTI- Contro, opposizione antibatterico, antivirus, antifurto
DIS- Negazione, separazione disfare, disordine, disattento
SUPER- Sopra, eccesso supermercato, supereroe, superare
SOTTO- Sotto, inferiorità sottomarino, sottovalutare, sottotitolo

🎭 PAROLE ALTERATE

Le parole alterate sono parole che modificano leggermente il significato della parola base usando suffissi speciali che esprimono dimensione, affetto o disprezzo!

🎨 Le alterazioni NON cambiano il significato principale della parola, ma aggiungono una sfumatura!

🎯 I 4 Tipi di Alterazione:

📉 DIMINUTIVI

Indicano qualcosa di PICCOLO

Gatto → GATTINO

Suffissi: -INO, -ETTO, -ELLO, -UCCIO

Casa → Casetta
Libro → Libretto
Albero → Alberello
Cane → Cagnolino

📈 ACCRESCITIVI

Indicano qualcosa di GRANDE

Libro → LIBRONE

Suffissi: -ONE, -OTTO

Ragazzo → Ragazzone
Casa → Casone
Pancia → Pancione
Isola → Isolotto

💖 VEZZEGGIATIVI

Esprimono AFFETTO

Casa → CASUCCIA

Suffissi: -UCCIO, -UZZO, -OLINO

Bambino → Bambinuccio
Cane → Cagnolino
Parola → Parolina
Pietra → Pietruzza

😠 PEGGIORATIVI

Esprimono DISPREZZO

Tempo → TEMPACCIO

Suffissi: -ACCIO, -ASTRO, -UCOLO

Poeta → Poetastro
Parola → Parolaccia
Ragazzo → Ragazzaccio
Uomo → Omaccio

🔵 PARASINTESI (Prefisso + Suffisso Insieme)

La parasintesi è un processo speciale dove aggiungiamo CONTEMPORANEAMENTE un prefisso E un suffisso alla parola base. Entrambi sono necessari!

Prefisso + Radice

2️⃣ SUFFISSAZIONE

Radice + Suffisso

Esempi: Gioc-ATORE, Felice-MENTE, Lavor-AZIONE, Pian-ISTA

Prefisso + Radice + Suffisso (insieme!)
