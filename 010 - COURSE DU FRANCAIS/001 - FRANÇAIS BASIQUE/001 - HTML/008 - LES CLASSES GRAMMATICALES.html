📚 Les Classes Grammaticales

Les 9 natures de mots en français

💡 Qu'est-ce qu'une classe grammaticale ?

La classe grammaticale (ou nature) d'un mot indique sa catégorie. Elle ne change jamais, même si le mot change de forme. Il existe 9 classes grammaticales en français.

🔀 Les Deux Grandes Catégories

🔄 Mots Variables

5 classes

Ces mots peuvent changer de forme (genre, nombre, personne, temps...)

📌 Nom • Déterminant • Adjectif • Pronom • Verbe

🔒 Mots Invariables

4 classes

Ces mots ne changent jamais de forme

📌 Adverbe • Préposition • Conjonction • Interjection

🔄 Les 5 Classes Variables

🏷️
Le Nom
Mot qui désigne une personne, un animal, un objet, un lieu, une idée ou un sentiment. Il a un genre (masculin/féminin) et un nombre (singulier/pluriel).
✨ Exemples :
• Nom commun : chat, table, bonheur
• Nom propre : Paris, Marie, France
🎯
Le Déterminant
Mot qui se place devant le nom pour le préciser. Il s'accorde en genre et en nombre avec le nom qu'il accompagne.
✨ Exemples :
• Articles : le, la, un, des
• Possessifs : mon, ta, ses, notre
• Démonstratifs : ce, cette, ces
🎨
L'Adjectif
Mot qui qualifie ou précise le nom. Il s'accorde en genre et en nombre avec le nom qu'il qualifie.
✨ Exemples :
• Qualificatifs : beau, grand, joyeux
• Dans une phrase : Un petit chat noir
👤
Le Pronom
Mot qui remplace un nom ou un groupe nominal pour éviter les répétitions. Il varie selon la personne, le genre et le nombre.
✨ Exemples :
• Personnels : je, tu, il, nous
• Possessifs : le mien, la tienne
• Démonstratifs : celui-ci, cela
⚡
Le Verbe
Mot qui exprime une action ou un état. Il se conjugue selon le mode, le temps, la personne et le nombre. C'est le noyau de la phrase.
✨ Exemples :
• Action : manger, courir, chanter
• État : être, sembler, paraître

🔒 Les 4 Classes Invariables

💫
L'Adverbe
Mot invariable qui modifie ou précise le sens d'un verbe, d'un adjectif ou d'un autre adverbe. Il apporte des informations sur le lieu, le temps, la manière, la quantité...
✨ Exemples :
• Manière : doucement, vite
• Temps : hier, demain, maintenant
• Lieu : ici, là-bas, partout
🔗
La Préposition
Mot invariable qui introduit un complément et établit un lien entre deux mots ou groupes de mots.
✨ Exemples :
à, de, par, pour, sans
dans, sur, sous, avec, chez
🌉
La Conjonction
Mot invariable qui relie deux mots, groupes de mots ou propositions. On distingue les conjonctions de coordination et de subordination.
✨ Exemples :
• Coordination : mais, ou, et, donc
• Subordination : que, quand, si, parce que
❗
L'Interjection
Mot invariable qui exprime une émotion vive, un sentiment soudain. Elle est souvent suivie d'un point d'exclamation.
✨ Exemples :
Ah !, Oh !, Hélas !
Bravo !, Aïe !, Chut !

💡 Astuces pour Identifier les Classes

🎯 Méthodes Pratiques

1 Le NOM : Peut être précédé d'un déterminant (le, un, mon...)
2 Le VERBE : Peut être conjugué, essayez de changer le temps
3 L'ADJECTIF : Répond aux questions "Comment est...?" ou "Quel genre de...?"
4 L'ADVERBE : Souvent terminé par -ment, modifie le verbe
5 La PRÉPOSITION : Introduit un complément (à Paris, de Marie, pour toi)
6 Le PRONOM : Remplace un nom (il = le chat, elle = Marie)
