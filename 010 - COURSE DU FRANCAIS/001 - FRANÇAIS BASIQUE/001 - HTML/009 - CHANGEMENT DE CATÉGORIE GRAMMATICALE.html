Les Classes de Mots

Changements de catégorie grammaticale

En français, un même mot peut appartenir à différentes classes grammaticales selon son emploi dans la phrase. Ce phénomène s'appelle la dérivation impropre ou le changement de classe grammaticale. Découvrons ensemble les principales transformations possibles !

1. Les Principaux Changements

🔵 Adjectif → Nom

C'est la transformation la plus fréquente !

Le bleu du ciel est magnifique.
(bleu : adjectif de couleur → nom)
Le principal du collège est absent.
(principal : adjectif → nom désignant une personne)
Les riches et les pauvres.
(adjectifs qualificatifs → noms)

🟢 Verbe → Nom

L'infinitif peut devenir un nom

Le manger et le boire sont essentiels.
(infinitifs → noms)
Le savoir est une richesse.
(verbe savoir → nom)
Le rire est contagieux.
(verbe rire → nom)

🟡 Participe → Adjectif ou Nom

Un film passionnant. → adjectif
(participe présent → adjectif qualificatif)
Un enseignant dévoué. → nom
(participe présent → nom de métier)
Un enfant fatigué. → adjectif
(participe passé → adjectif qualificatif)

🔴 Adverbe → Nom

Le bien et le mal.
(adverbes → noms abstraits)
Le demain nous appartient.
(adverbe de temps → nom)

3. Comment Reconnaître le Changement ?

📌 Indices pour reconnaître un nom :

✓ Présence d'un déterminant (le, un, ce, mon...)
✓ Peut être précédé d'un adjectif
✓ Peut être sujet ou complément dans la phrase

📌 Indices pour reconnaître un adjectif :

✓ Qualifie un nom
✓ S'accorde en genre et en nombre avec ce nom
✓ Peut être supprimé sans rendre la phrase incorrecte
💡 Astuce : Pour identifier la classe grammaticale d'un mot, il faut toujours observer sa fonction et son rôle dans la phrase, pas seulement sa forme !

4. Exemples Comparatifs

Marcher est bon pour la santé. → verbe substantivé (nom)
Je vais marcher ce soir. → verbe à l'infinitif
Le français est ma langue maternelle. → nom
Un citoyen français. → adjectif
Le passé est derrière nous. → nom
L'année passée. → adjectif (participe passé)

Les changements de catégorie grammaticale enrichissent la langue française !
