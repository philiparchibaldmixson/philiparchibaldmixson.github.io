Les Autres Signes - Guide Complet

Au-delà des signes de ponctuation classiques (point, virgule, etc.), il existe de nombreux autres symboles que nous utilisons régulièrement dans l'écriture. Ces signes ont des usages spécifiques et enrichissent notre communication écrite. Découvrons-les ensemble ! 🎯

Les Signes Typographiques

'
L'Apostrophe
Usage : Remplace une voyelle élidée devant un mot commençant par une voyelle ou un h muet.
Exemples :
• le + ami = l'ami
• je + ai = j'ai
• que + il = qu'il
• si + il = s'il
Aujourd'hui, j'irai à l'école.
-
Le Trait d'Union
Usage : Relie des mots, des éléments composés, l'inversion sujet-verbe, les nombres.
Exemples :
• arc-en-ciel
• rendez-vous
• vingt-trois
• Est-ce que...?
Mon grand-père a soixante-quinze ans.
[ ]
Les Crochets
Usage : Ajoutent une précision dans une citation, indication phonétique, ou notation mathématique.
Exemples :
• « Il [Victor Hugo] était un grand poète. »
• Phonétique : [ʃa] pour "chat"
• Math : [0 ; 10] (intervalle fermé)
/
La Barre Oblique
Usage : Indique une alternative, sépare des éléments, notation de fractions ou dates.
Exemples :
• et/ou
• Il/Elle doit venir
• 08/11/2025
• 3/4 (trois quarts)
*
L'Astérisque
Usage : Renvoie à une note de bas de page, indique une omission, ou signale une forme incorrecte.
Exemples :
• Voir note* en bas de page
• Mot de passe : ****1234
• *Je suis allé (forme incorrecte en linguistique)
{ }
Les Accolades
Usage : Regroupent des éléments, utilisées en programmation, mathématiques, ou pour des ensembles.
Exemples :
• Ensemble : {1, 2, 3, 4}
• Programmation : if { code }
• Notation : {x ∈ ℝ}
@
L'Arobase (At)
Usage : Sépare le nom d'utilisateur du domaine dans les adresses email et réseaux sociaux.
Exemples :
• Email : contact@exemple.fr
• Twitter/X : @utilisateur
• Mention : @Marie dans le message
&
L'Esperluette (Et commercial)
Usage : Remplace "et" dans les raisons sociales, titres, ou contextes formels.
Exemples :
• Dupont & Fils
• Recherche & Développement
• Pierre & Marie (entreprise)
#
Le Dièse (Hashtag)
Usage : Mot-clé sur les réseaux sociaux, numéro, ou symbole musical.
Exemples :
• #Education
• #BonneJournée
• Chambre #123
• Do# (musique)
%
Le Pourcentage
Usage : Exprime une proportion sur cent, un taux, une réduction.
Exemples :
• 50% de réduction
• Taux de 3,5%
• 100% d'accord
• Réussite : 85%
°
Le Degré
Usage : Mesure d'angle, de température, ou ordinal (numéro).
Exemples :
• 25°C (température)
• Angle de 90°
• N° 1 (numéro un)
• 1er, 2e, 3e
$
Le Dollar
Usage : Symbole monétaire (dollar américain, canadien, etc.).
Exemples :
• Prix : 50$
• 100$ US
• Budget : 1 000$

📋 Catégories de Signes

1. Signes de regroupement

( ) Parenthèses • [ ] Crochets • { } Accolades
Usage : Isoler ou regrouper des informations

2. Signes de liaison

- Trait d'union • ' Apostrophe • & Esperluette
Usage : Relier des éléments entre eux

3. Signes de référence

* Astérisque • @ Arobase • # Dièse
Usage : Renvoyer à quelque chose ou identifier

4. Signes mathématiques et monétaires

% Pourcentage • $ Dollar • € Euro • ° Degré
Usage : Notations techniques et commerciales

💡 Astuces Pratiques

1. L'apostrophe : Ne pas confondre avec l'accent aigu (´). L'apostrophe est verticale ou légèrement inclinée : '

2. Le trait d'union : Toujours utilisé sans espace avant ni après. Ex : dix-sept, peut-être

3. Les crochets : Utiles pour ajouter une précision dans une citation sans modifier le texte original

4. L'arobase : Obligatoire dans les emails, se prononce "arobase" ou "at" en anglais

⚠️ Attention aux erreurs courantes

❌ l' ami → ✅ l'ami (pas d'espace après l'apostrophe)
❌ arc - en - ciel → ✅ arc-en-ciel (pas d'espace autour du trait d'union)
❌ 50 % → ✅ 50 % (espace avant le symbole %)
❌ 25° C → ✅ 25 °C (espace avant °, pas d'espace avant C)
