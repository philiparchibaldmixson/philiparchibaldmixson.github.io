⚧️ Le Genre en Français

Maîtriser le Masculin et le Féminin

Qu'est-ce que le Genre Grammatical ?

Le genre grammatical est une caractéristique fondamentale du français. Chaque nom est soit masculin, soit féminin. Cette distinction affecte les articles, les adjectifs et les pronoms qui accompagnent le nom.

💡 Important !

Le genre grammatical est souvent arbitraire et ne correspond pas toujours au sexe biologique. Par exemple, "une personne" est toujours féminin, même pour un homme, et "un bébé" est toujours masculin, même pour une fille !

Les Deux Genres

♂️

Masculin

Articles : le, un, les, des

  • 📘 le livre
  • 🐱 un chat
  • 👨 le garçon
  • 🌳 l'arbre
  • ☀️ le soleil
  • 🚗 un véhicule
♀️

Féminin

Articles : la, une, les, des

  • 🏠 la maison
  • 🐱 une chatte
  • 👧 la fille
  • 🌸 la fleur
  • 🌙 la lune
  • 🚗 une voiture

Reconnaître le Genre par la Terminaison

Terminaisons Généralement Masculines

🔵 Terminaisons masculines courantes

  • -age : le fromage, le garage, le voyage, le courage
  • -ment : le gouvernement, le développement, le logement
  • -eau : le château, le bureau, le cadeau, le bateau
  • -phone : le téléphone, le microphone, le saxophone
  • -scope : le microscope, le télescope, le stéthoscope
  • -isme : le tourisme, le réalisme, le capitalisme
  • -oir : le miroir, le couloir, leoir

⚠️ Exceptions importantes :

  • -age : la page, la plage, la cage, la rage, l'image
  • -eau : l'eau, la peau

Terminaisons Généralement Féminines

🌸 Terminaisons féminines courantes

  • -tion : la nation, la création, l'action, la solution
  • -sion : la télévision, la décision, la passion
  • -té : la liberté, la beauté, la vérité, la société
  • -ée : la journée, la durée, l'idée, la soirée
  • -ie : la vie, la maladie, la pharmacie, la théorie
  • -ure : la nature, la culture, la voiture, la peinture
  • -ance/-ence : la France, la danse, la science, la prudence
  • -ette : la cigarette, la baguette, la recette
  • -esse : la richesse, la jeunesse, la tristesse

⚠️ Exceptions importantes :

  • -té : le côté, le comité, le député, l'été, le pâté
  • -ée : le musée, le lycée, le scarabée

Formation du Féminin

1️⃣ Règle Générale : Ajout du -E

On ajoute simplement -e au masculin

Masculin :

un ami

Féminin :

une amie

  • un étudiant → une étudiante
  • un avocat → une avocate
  • un français → une française

2️⃣ Doublement de la Consonne + E

Certains mots doublent la consonne finale avant d'ajouter -e

  • un chat → une chatte
  • un lion → une lionne
  • un chien → une chienne
  • un paysan → une paysanne
  • un Parisien → une Parisienne
  • un musicien → une musicienne
  • bon → bonne
  • européen → européenne

3️⃣ Changement de -ER en -ÈRE

  • un boulanger → une boulangère
  • un étranger → une étrangère
  • un infirmier → une infirmière
  • un premier → une première
  • un dernier → une dernière

4️⃣ Changement de -EUR en -EUSE

  • un vendeur → une vendeuse
  • un chanteur → une chanteuse
  • un danseur → une danseuse
  • un coiffeur → une coiffeuse
  • heureux → heureuse

⚠️ Mais -EUR devient -RICE pour certains mots :

  • un acteur → une actrice
  • un directeur → une directrice
  • un lecteur → une lectrice
  • un traducteur → une traductrice

5️⃣ Changement de -TEUR en -TRICE

  • un acteur → une actrice
  • un instituteur → une institutrice
  • un dessinateur → une dessinatrice
  • un admirateur → une admiratrice

6️⃣ Changement de -F en -VE

  • un veuf → une veuve
  • neuf → neuve
  • actif → active
  • sportif → sportive

7️⃣ Changement de -X en -SE

  • heureux → heureuse
  • jaloux → jalouse
  • sérieux → sérieuse
  • curieux → curieuse

Conseils et Astuces

✅ Comment mémoriser le genre ?
  • Apprendre le nom avec son article : toujours dire "le livre" et pas juste "livre"
  • Grouper les mots par terminaison : les mots en -tion sont presque toujours féminins
  • Utiliser des couleurs : bleu pour le masculin, rose pour le féminin
  • Faire des associations : créer des phrases mnémotechniques
⚠️ Pièges à éviter !
  • Ne pas se fier à la logique : "une personne" peut désigner un homme !
  • Attention aux faux amis : certains mots ont un genre différent dans d'autres langues
  • Les noms de pays : généralement féminins s'ils finissent par -e (la France), masculins sinon (le Brésil)
  • Les lettres de l'alphabet : sont toujours féminines (la lettre A, la lettre B)

🌍 Genre des Pays et Continents

Masculin :

le Brésil, le Portugal, le Japon, le Canada, le Mexique, le Maroc

Féminin :

la France, l'Espagne, l'Italie, la Chine, la Russie, l'Allemagne

Règle simple : Si le pays finit par -E, il est généralement féminin. Exceptions : le Mexique, le Mozambique, le Cambodge...
