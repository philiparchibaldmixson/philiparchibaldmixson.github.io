🔢 Le Nombre en Français

Maîtriser le Singulier et le Pluriel

Qu'est-ce que le Nombre Grammatical ?

Le nombre grammatical est une catégorie qui indique la quantité : un seul être ou objet (singulier) ou plusieurs (pluriel). En français, la formation du pluriel suit des règles précises selon la terminaison du mot.

💡 Important !

Le pluriel en français ne se forme pas toujours avec un simple "s". Il existe de nombreuses exceptions et règles spécifiques à connaître pour bien écrire !

Singulier vs Pluriel

1️⃣

Singulier

Indique une seule personne, un seul animal ou objet

  • 📘 le livre
  • 🐱 le chat
  • 🌸 la fleur
  • 👨 l'homme
  • 🏠 la maison
2️⃣

Pluriel

Indique deux ou plusieurs personnes, animaux ou objets

  • 📚 les livres
  • 🐱🐱 les chats
  • 🌸🌸 les fleurs
  • 👨👨 les hommes
  • 🏠🏠 les maisons

Règles de Formation du Pluriel

1️⃣ Règle Générale

On ajoute un -S au singulier

  • chat → chats
  • table → tables
  • ami → amis
  • voiture → voitures
  • maison → maisons

2️⃣ Mots Terminés par -S, -X ou -Z

Règle : INVARIABLES (pas de changement)

  • le fils → les fils
  • la souris → les souris
  • le prix → les prix
  • la voix → les voix
  • le nez → les nez
  • le gaz → les gaz

3️⃣ Mots Terminés par -AU, -EU, -EAU

On ajoute un -X

  • tuyau → tuyaux
  • château → châteaux
  • cadeau → cadeaux
  • jeu → jeux
  • cheveu → cheveux

⚠️ Exceptions :

  • pneu → pneus
  • bleu → bleus
  • landau → landaus
  • sarrau → sarraus

4️⃣ Mots Terminés par -OU

Règle générale : on ajoute -S

  • clou → clous
  • fou → fous
  • trou → trous

⚠️ 7 Exceptions qui prennent -X :

  • bijou → bijoux
  • caillou → cailloux
  • chou → choux
  • genou → genoux
  • hibou → hiboux
  • joujou → joujoux
  • pou → poux

Astuce : « Viens mon chou, mon bijou, mon joujou, sur mes genoux, et jette des cailloux à ce hibou plein de poux. »

5️⃣ Mots Terminés par -AL

-AL devient -AUX

  • cheval → chevaux
  • journal → journaux
  • animal → animaux
  • hôpital → hôpitaux
  • général → généraux

⚠️ Exceptions qui prennent -S :

  • bal → bals
  • carnaval → carnavals
  • festival → festivals
  • récital → récitals
  • chacal → chacals

6️⃣ Mots Terminés par -AIL

Règle générale : on ajoute -S

  • détail → détails
  • rail → rails
  • chandail → chandails

⚠️ Exceptions qui deviennent -AUX :

  • travail → travaux
  • vitrail → vitraux
  • émail → émaux
  • corail → coraux
  • bail → baux

Pluriel des Noms Composés

🔗 Nom + Nom

Les deux noms prennent le pluriel

Singulier :

un chou-fleur

Pluriel :

des choux-fleurs

  • un oiseau-mouche → des oiseaux-mouches
  • un wagon-lit → des wagons-lits

🔗 Nom + Adjectif ou Adjectif + Nom

Les deux mots varient

Singulier :

un coffre-fort

Pluriel :

des coffres-forts

  • un grand-père → des grands-pères
  • une belle-sœur → des belles-sœurs

🔗 Verbe + Nom

Le verbe reste invariable, seul le nom varie

Singulier :

un tire-bouchon

Pluriel :

des tire-bouchons

  • un porte-monnaie → des porte-monnaie (le nom reste au singulier car on porte LA monnaie)
  • un couvre-lit → des couvre-lits
  • un essuie-main → des essuie-mains

🔗 Mot Invariable + Nom

Seul le nom varie

  • un avant-bras → des avant-bras
  • un sans-abri → des sans-abri
  • un en-tête → des en-têtes

Cas Particuliers et Pluriels Irréguliers

Singulier Pluriel Particularité
œil yeux Pluriel complètement irrégulier
monsieur messieurs Forme différente
madame mesdames Forme différente
mademoiselle mesdemoiselles Forme différente
ciel cieux / ciels Deux formes selon le sens
aïeul aïeuls / aïeux aïeuls (grands-parents), aïeux (ancêtres)
œuf œufs Prononciation change : [œf] → [ø]
bœuf bœufs Prononciation change : [bœf] → [bø]
os os Prononciation change : [ɔs] → [o]

Noms Toujours au Pluriel

📌 Certains noms n'existent qu'au pluriel :
  • les gens (les personnes)
  • les mœurs (les habitudes, coutumes)
  • les funérailles (cérémonie)
  • les environs (les alentours)
  • les frais (dépenses)
  • les archives (documents anciens)
  • les décombres (ruines)
  • les ténèbres (obscurité)

Noms Étrangers

🌍 Pluriel des Mots d'Origine Étrangère

En général, les mots étrangers francisés prennent un -S :

  • un sandwich → des sandwichs
  • un album → des albums
  • un scénario → des scénarios
  • un maximum → des maximums

⚠️ Certains gardent leur pluriel d'origine :

  • un gentleman → des gentlemen (anglais)
  • un match → des matchs ou match (les deux acceptés)

L'Accord en Nombre

✅ Règle de Concordance

Les articles, adjectifs et participes passés s'accordent en nombre avec le nom :

  • Le petit chat noir (singulier masculin)
  • Les petits chats noirs (pluriel masculin)
  • La belle fleur rouge (singulier féminin)
  • Les belles fleurs rouges (pluriel féminin)
⚠️ Attention aux Pièges !
  • Après "un kilo de", "beaucoup de", etc. : le nom qui suit prend le pluriel
    → un kilo de pommes, beaucoup d'amis
  • Les noms de couleur composés sont invariables
    → des chemises bleu clair (pas de -s)
  • Les couleurs qui sont des noms de choses restent invariables
    → des robes orange, des yeux noisette

Astuces Mnémotechniques

🎯 Pour retenir les 7 mots en -OU qui prennent -X :

« Viens mon chou, mon bijou, mon joujou, sur mes genoux, et jette des cailloux à ce hibou plein de poux. »

🎯 Pour retenir les exceptions en -AL qui prennent -S :

« Les bals, carnavals et festivals sont des récitals de chacals. »

🎯 Pour retenir les mots en -AIL qui deviennent -AUX :

« Le travail des vitraux, baux, coraux et émaux. »
