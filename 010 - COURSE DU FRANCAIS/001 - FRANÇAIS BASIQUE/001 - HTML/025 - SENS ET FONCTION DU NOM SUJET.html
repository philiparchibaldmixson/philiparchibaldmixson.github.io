🇫🇷 Le Nom Sujet

Sens et Fonction du Nom Sujet

🎯 Définition essentielle : Le nom sujet est l'élément de la phrase qui fait ou subit l'action exprimée par le verbe. C'est l'un des constituants fondamentaux de la phrase française, sans lequel une phrase ne peut généralement pas exister !

1Qu'est-ce que le sujet ?

Définition complète
Le sujet est le nom (ou groupe nominal) qui désigne l'être ou la chose qui effectue l'action du verbe, ou qui se trouve dans l'état exprimé par le verbe. Le verbe s'accorde toujours en nombre et en personne avec le sujet.
Exemples de base
Le chat dort sur le canapé.
Marie mange une pomme.
Les enfants jouent dans le jardin.
Mon frère et ma sœur arrivent demain.
Point important

Le sujet répond toujours à la question : "Qui est-ce qui...?" ou "Qu'est-ce qui...?" posée avant le verbe.

2Comment identifier le sujet ?

Méthode principale : La question "Qui/Qu'est-ce qui ?"

Pour trouver le sujet, il suffit de poser la question "Qui est-ce qui..." (pour une personne) ou "Qu'est-ce qui..." (pour une chose) devant le verbe.

1 Repérez le verbe conjugué dans la phrase.
2 Posez la question "Qui est-ce qui..." ou "Qu'est-ce qui..." + verbe ?
3 La réponse à cette question est le sujet.
Application pratique
Le soleil brille dans le ciel.
→ Qu'est-ce qui brille ? → Le soleil
Les étudiants travaillent à la bibliothèque.
→ Qui est-ce qui travaille ? → Les étudiants
Cette histoire me passionne.
→ Qu'est-ce qui me passionne ? → Cette histoire
2 Méthode de l'encadrement

On peut aussi encadrer le sujet par "C'est... qui" ou "Ce sont... qui"

Les oiseaux chantent. → Ce sont les oiseaux qui chantent.
Pierre téléphone. → C'est Pierre qui téléphone.
3 Vérification par l'accord

Le verbe s'accorde toujours avec le sujet. Changez le sujet, le verbe change aussi !

Le chien aboie. → Les chiens aboient.

3Les différents types de sujets

Nom propre

Définition : Désigne une personne ou un lieu spécifique.

Paris est une belle ville.
Sophie adore le chocolat.
Nom commun

Définition : Désigne une catégorie générale d'êtres ou de choses.

Le livre est sur la table.
Les voitures roulent vite.
Groupe nominal

Définition : Nom accompagné de ses déterminants et/ou compléments.

Le petit garçon blond joue.
Ma sœur aînée voyage.
Pronom

Définition : Remplace un nom pour éviter la répétition.

Il travaille beaucoup.
Nous partons en vacances.
Infinitif

Définition : Le verbe à l'infinitif peut être sujet.

Lire enrichit l'esprit.
Voyager ouvre l'esprit.
Proposition

Définition : Toute une proposition peut être sujet.

Que tu réussisses me réjouit.
Qui vivra verra.

4La place du sujet dans la phrase

Ordre normal : Sujet + Verbe
Marie chante une chanson.
Les étoiles brillent dans le ciel.
Inversion : Verbe + Sujet

Dans certains cas, le sujet est placé après le verbe :

Dans les questions :
Vient-il demain ?
Après certains adverbes :
Peut-être viendra-t-il.
Avec les verbes de parole :
"Bonjour", dit Pierre.
En style littéraire :
Ainsi parlait le sage.
Astuce importante

Même quand le sujet est inversé, il reste le sujet ! Le verbe s'accorde toujours avec lui, quelle que soit sa position dans la phrase.

5L'accord du verbe avec le sujet

Règle fondamentale
Le verbe s'accorde toujours en nombre (singulier/pluriel) et en personne (1ère, 2ème, 3ème) avec son sujet.
Exemples d'accord
Le chat (singulier) dort (singulier).
Les chats (pluriel) dorment (pluriel).
Tu (2ème personne) manges (2ème personne).
Nous (1ère personne pluriel) mangeons (1ère personne pluriel).
Cas particulier : Plusieurs sujets

Quand il y a plusieurs sujets, le verbe se met au pluriel :

Marie et Pierre arrivent (pluriel).
Le chien, le chat et l'oiseau jouent ensemble (pluriel).
Attention aux pièges !

Le verbe ne s'accorde JAMAIS avec le complément !

❌ Incorrect : La boîte de chocolats sont sur la table.
✅ Correct : La boîte de chocolats est sur la table.
(Le sujet est "la boîte", pas "chocolats")

6Sujet réel et sujet apparent

Avec les verbes impersonnels

Certains verbes ont un sujet apparent (il) et un sujet réel qui vient après :

Il (apparent) pleut des cordes (réel).
Il (apparent) faut du courage (réel).
Il (apparent) arrive des problèmes (réel).
Il (apparent) existe des solutions (réel).
Point clé

Le pronom "il" dans ces constructions est le sujet grammatical, mais le sujet logique (qui a vraiment du sens) vient après le verbe.

Points clés à retenir
  • Le sujet est l'élément qui fait ou subit l'action du verbe
  • On le trouve en posant la question "Qui/Qu'est-ce qui + verbe ?"
  • Le verbe s'accorde TOUJOURS avec le sujet
  • Le sujet peut être un nom, un pronom, un infinitif, une proposition
  • Le sujet se place généralement avant le verbe, mais pas toujours
  • Attention à ne pas confondre le sujet avec les compléments
  • Plusieurs sujets = verbe au pluriel
  • Il existe des sujets apparents et des sujets réels
