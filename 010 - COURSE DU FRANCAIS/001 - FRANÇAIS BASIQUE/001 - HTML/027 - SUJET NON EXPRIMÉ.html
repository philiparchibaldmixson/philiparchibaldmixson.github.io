🇫🇷 Le Sujet Non Exprimé

Sujet et Complément d'Agent

Grammaire Française

👻 Concept fascinant : En français, le sujet n'est pas toujours exprimé dans la phrase ! Il peut être sous-entendu, implicite ou omis selon le contexte. Cette particularité grammaticale est essentielle pour comprendre la construction de nombreuses phrases françaises.

1Qu'est-ce qu'un sujet non exprimé ?

Définition
Un sujet non exprimé (ou sujet implicite) est un sujet qui n'apparaît pas dans la phrase mais qui est néanmoins compris par le contexte, la conjugaison du verbe ou la construction de la phrase. Le verbe s'accorde avec ce sujet même s'il n'est pas visible.
Exemples de base
Viens ici !
→ Sujet sous-entendu : (tu)
Mangeons ensemble !
→ Sujet sous-entendu : (nous)
Finissez votre travail.
→ Sujet sous-entendu : (vous)
Point important

Même si le sujet n'est pas exprimé, le verbe s'accorde avec lui ! La terminaison du verbe nous indique quel est le sujet sous-entendu.

2Les différents cas

1. Mode Impératif
À l'impératif, le sujet n'est JAMAIS exprimé. Il est toujours sous-entendu.
Regarde ce paysage !
(tu) regarde
Partons maintenant.
(nous) partons
Écoutez attentivement.
(vous) écoutez
Soyons courageux !
(nous) soyons
2. Mode Infinitif
L'infinitif n'a pas de sujet exprimé. Le sujet est déterminé par le contexte.
Traverser la rue est dangereux.
→ Sujet général (action)
Ne pas fumer.
→ Ordre général (vous/tout le monde)
Tourner à droite.
→ Instruction (vous)
Agiter avant emploi.
→ Mode d'emploi (vous)
3. Mode Participe
Le participe présent ou passé peut avoir un sujet non exprimé.
Arrivé à Paris, je suis allé à l'hôtel.
→ Sujet sous-entendu : (je)
Sachant la vérité, elle a tout avoué.
→ Sujet sous-entendu : (elle)
Fatigués, nous sommes rentrés.
→ Sujet sous-entendu : (nous)
4. Ellipse du sujet
Dans certaines constructions, le sujet est omis pour éviter la répétition.
Marie chante et danse.
→ Sujet omis : (Marie) danse
Pierre lit, Paul écrit.
→ (Paul) est répété
Je lis et comprends le texte.
→ Sujet omis : (je) comprends
5. Propositions subordonnées
Dans certaines subordonnées, le sujet peut être omis.
Avant de partir, ferme la porte.
→ Sujet sous-entendu : (tu)
Pour réussir, il faut travailler.
→ Sujet général (on/tout le monde)
Après avoir mangé, nous sommes partis.
→ Sujet sous-entendu : (nous)
6. Phrases nominales
Certaines phrases sans verbe sous-entendent un sujet.
Magnifique, ce tableau !
→ (Ce tableau est) magnifique
Extraordinaire !
→ (C'est/Cela est) extraordinaire
Quel courage !
→ Exclamation sans sujet ni verbe exprimés

3L'impératif : Le cas le plus courant

Règle fondamentale
À l'impératif, le sujet n'est JAMAIS écrit. Il est toujours sous-entendu et correspond à la personne à qui l'on s'adresse : tu, nous ou vous.
Les trois personnes de l'impératif
2ème personne du singulier (tu) :
Mange ta soupe !
→ (Tu) mange ta soupe
1ère personne du pluriel (nous) :
Allons au cinéma !
→ (Nous) allons au cinéma
2ème personne du pluriel (vous) :
Faites attention !
→ (Vous) faites attention
Indicatif (sujet exprimé) Impératif (sujet non exprimé)
Tu viens ici. Viens ici !
Nous partons maintenant. Partons maintenant !
Vous écoutez le professeur. Écoutez le professeur !
Tu finis ton travail. Finis ton travail !
Nous sommes patients. Soyons patients !
Attention à l'erreur courante !

❌ Incorrect : "Tu viens ici !" (à l'impératif, on ne met pas le sujet)

✅ Correct : "Viens ici !"

4L'infinitif de narration et d'instruction

📖 Infinitif de narration

Employé dans les récits, souvent avec "et" ou "de" :

Et la grenouille de sauter !
→ = et la grenouille sauta
Les enfants de rire !
→ = les enfants rirent
📋 Infinitif d'instruction

Utilisé dans les modes d'emploi, recettes, panneaux :

Couper les légumes en dés.
→ (Vous devez) couper
Ne pas dépasser la dose prescrite.
→ (Vous ne devez pas) dépasser
Tourner à gauche après le feu.
→ (Vous devez) tourner
🚫 Infinitif de défense

Exprime une interdiction générale :

Ne pas fumer.
→ Défense de fumer
Ne pas toucher.
→ Il est interdit de toucher
Ne pas marcher sur la pelouse.
→ Interdiction de marcher

5Le participe avec sujet non exprimé

Règle importante

Quand un participe (présent ou passé) commence une phrase ou une proposition, son sujet non exprimé doit être le même que le sujet de la proposition principale.

Participe présent
Sachant la vérité, il a tout avoué.
→ (Il) sachant = C'est lui qui sait
Ayant faim, nous sommes allés au restaurant.
→ (Nous) ayant faim
Étant malade, elle est restée chez elle.
→ (Elle) étant malade
Participe passé
Arrivé à la gare, je suis monté dans le train.
→ (Je) arrivé
Fatigués par le voyage, nous nous sommes reposés.
→ (Nous) fatigués
Surpris par la nouvelle, ils n'ont rien dit.
→ (Ils) surpris
Erreur fréquente : Le participe détaché

❌ Incorrect : "Arrivé à Paris, la Tour Eiffel m'a impressionné."

→ Ce n'est pas la Tour Eiffel qui est arrivée !

✅ Correct : "Arrivé à Paris, j'ai été impressionné par la Tour Eiffel."

6Comment identifier le sujet non exprimé ?

1 Identifiez le mode du verbe : impératif, infinitif, participe ?
2 Analysez la terminaison du verbe pour connaître la personne.
3 Regardez le contexte : qui parle ? à qui ? de quoi ?
4 Trouvez le sujet logique dans la phrase principale si c'est une subordonnée.
5 Reformulez mentalement la phrase avec le sujet exprimé pour vérifier.
Exercice d'identification
Phrase : "Parti tôt, il a évité les embouteillages."
→ Sujet non exprimé de "Parti" : (il)
→ Vérification : "Étant parti tôt, il a évité..."
Phrase : "Écoutez bien cette explication !"
→ Mode : Impératif
→ Terminaison : -ez = 2ème personne du pluriel
→ Sujet : (vous)
Phrase : "Ne pas déranger."
→ Mode : Infinitif de défense
→ Sujet général : (vous / tout le monde)
Points clés à retenir
  • Le sujet non exprimé est sous-entendu mais le verbe s'accorde avec lui
  • À l'impératif, le sujet n'est JAMAIS exprimé (tu, nous, vous)
  • L'infinitif n'a pas de sujet déterminé (sujet général ou contextuel)
  • Le participe a un sujet non exprimé qui doit être le même que celui de la principale
  • Dans les phrases coordonnées, on peut omettre le sujet pour éviter la répétition
  • Les panneaux, modes d'emploi utilisent l'infinitif sans sujet
  • Le contexte permet toujours d'identifier le sujet sous-entendu
  • Attention aux erreurs de participe détaché (incohérence de sujet)
