🇫🇷 Sujet Réel et Sujet Apparent

Sujet et Complément d'Agent

Grammaire Française

🔍 Distinction fondamentale : En français, certaines constructions impersonnelles présentent deux sujets : un sujet apparent (grammatical) qui est toujours "il", et un sujet réel (logique) qui porte le véritable sens de la phrase. Cette dualité est essentielle pour comprendre la structure de nombreuses phrases françaises !

1Sujet Apparent vs Sujet Réel

🔵 Sujet Apparent
Définition

Le sujet apparent (ou sujet grammatical) est le pronom "il" qui ne représente rien de précis. C'est le sujet formel de la phrase.

Il pleut.
Il faut du courage.
Il est arrivé un accident.

✓ Toujours à la 3ème personne du singulier
✓ Toujours le pronom "il"
✓ Ne peut pas être remplacé

⇄
🔴 Sujet Réel
Définition

Le sujet réel (ou sujet logique) est l'élément qui porte vraiment le sens. C'est ce qui fait réellement l'action ou subit l'état.

La pluie tombe.
→ sens réel de "il pleut"
du courage
→ ce qui est nécessaire
un accident
→ ce qui est arrivé

✓ Peut varier en nombre
✓ Porte le sens véritable
✓ Souvent placé après le verbe

2Définitions et Caractéristiques

Le Sujet Apparent
Le sujet apparent est un pronom impersonnel "il" qui sert uniquement à la construction grammaticale de la phrase. Il ne désigne aucune personne ni aucune chose concrète. Il est obligatoire car en français, un verbe conjugué doit avoir un sujet.
Le Sujet Réel
Le sujet réel est l'élément qui a vraiment du sens dans la phrase. C'est lui qui fait l'action ou qui subit l'état exprimé par le verbe. Il apparaît généralement après le verbe et peut être un nom, un groupe nominal, un infinitif ou une proposition.
Analyse comparative
Il arrive des touristes.
→ Sujet apparent : Il (grammatical)
→ Sujet réel : des touristes (logique) - ce sont eux qui arrivent
Il faut de la patience.
→ Sujet apparent : Il (grammatical)
→ Sujet réel : de la patience (logique) - c'est ce qui est nécessaire
Il existe plusieurs solutions.
→ Sujet apparent : Il (grammatical)
→ Sujet réel : plusieurs solutions (logique) - ce sont elles qui existent

3Les Verbes Impersonnels avec Sujet Réel

Il faut

Exprime la nécessité

Il faut du temps.
→ Le temps est nécessaire
Il faut partir.
→ Partir est nécessaire
Il faut que tu viennes.
→ Ta venue est nécessaire
Il arrive

Exprime un événement qui se produit

Il arrive des problèmes.
→ Les problèmes surviennent
Il arrive qu'on se trompe.
→ Les erreurs se produisent
Il arrive un train.
→ Le train arrive
Il existe

Exprime l'existence

Il existe plusieurs méthodes.
→ Les méthodes existent
Il existe une solution.
→ La solution existe
Il n'existe pas de réponse simple.
→ Aucune réponse simple n'existe
Il reste

Exprime ce qui subsiste

Il reste trois places.
→ Trois places subsistent
Il reste du pain.
→ Du pain subsiste
Il reste beaucoup à faire.
→ Beaucoup de travail subsiste
Il manque

Exprime une absence

Il manque cinq euros.
→ Cinq euros font défaut
Il manque des informations.
→ Les informations font défaut
Il manque quelqu'un.
→ Quelqu'un fait défaut
Il se passe

Exprime un événement

Il se passe quelque chose.
→ Quelque chose se produit
Il se passe des événements étranges.
→ Des événements se produisent
Que se passe-t-il ?
→ Quel événement se produit ?

4L'Accord du Verbe

Règle fondamentale

Le verbe impersonnel s'accorde TOUJOURS avec le sujet apparent "il", donc il reste toujours au singulier, même si le sujet réel est au pluriel !

Phrase Sujet Réel Accord
Il arrive des touristes. des touristes (pluriel) ✅ SINGULIER (arrive)
Il existe plusieurs solutions. plusieurs solutions (pluriel) ✅ SINGULIER (existe)
Il reste trois places. trois places (pluriel) ✅ SINGULIER (reste)
Il manque des informations. des informations (pluriel) ✅ SINGULIER (manque)
Erreurs à éviter
❌ Incorrect : Il arrivent des problèmes.
→ Le verbe ne s'accorde PAS avec le sujet réel !
✅ Correct : Il arrive des problèmes.
→ Le verbe s'accorde avec le sujet apparent "il" (singulier)
❌ Incorrect : Il restent trois places.
→ Erreur d'accord !
✅ Correct : Il reste trois places.
→ Toujours au singulier !

5Nature du Sujet Réel

Le sujet réel peut être :
1. Un nom ou groupe nominal
Il arrive un accident.
Il existe de nombreuses possibilités.
Il reste deux heures.
2. Un verbe à l'infinitif
Il faut partir.
Il suffit de demander.
Il vaut mieux attendre.
3. Une proposition subordonnée
Il faut que tu viennes.
Il arrive qu'on se trompe.
Il se peut qu'il pleuve.

6Comment Identifier les Deux Sujets ?

1 Repérez le "il" impersonnel : c'est le sujet apparent (grammatical).
2 Posez la question : "Qu'est-ce qui..." ou "Qui est-ce qui..." après le verbe.
3 La réponse à cette question est le sujet réel (logique).
4 Transformez la phrase en mettant le sujet réel en début de phrase.
5 Vérifiez : le sujet réel porte le sens véritable de l'action.
Application pratique
Phrase : Il existe plusieurs solutions.

Étape 1 : Sujet apparent = Il
Étape 2 : Qu'est-ce qui existe ? → plusieurs solutions
Étape 3 : Sujet réel = plusieurs solutions
Étape 4 : Transformation : "Plusieurs solutions existent."
Étape 5 : ✓ Ce sont bien les solutions qui existent !
Phrase : Il faut du courage.

Étape 1 : Sujet apparent = Il
Étape 2 : Qu'est-ce qui est nécessaire ? → du courage
Étape 3 : Sujet réel = du courage
Étape 4 : Transformation : "Du courage est nécessaire."
Étape 5 : ✓ C'est bien le courage qui est nécessaire !
Points clés à retenir
  • Le sujet apparent est toujours "il" - il n'a pas de sens propre
  • Le sujet réel porte le véritable sens de la phrase
  • Le sujet apparent est grammatical, le sujet réel est logique
  • Le verbe s'accorde avec le sujet apparent (toujours singulier)
  • Le sujet réel se trouve généralement après le verbe
  • Le sujet réel peut être un nom, un infinitif ou une proposition
  • Verbes courants : il faut, il arrive, il existe, il reste, il manque, il se passe
  • Pour trouver le sujet réel : posez la question "Qu'est-ce qui..." après le verbe
