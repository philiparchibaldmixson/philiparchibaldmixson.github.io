🇫🇷 Le Complément d'Agent

Sujet et Complément d'Agent

Grammaire Française

🎯 Définition essentielle : Le complément d'agent est un complément qui apparaît dans les phrases à la voix passive. Il indique qui fait l'action du verbe. À la voix active, cet élément devient le sujet. C'est un concept fondamental pour comprendre la transformation actif ↔ passif !

1Actif ↔ Passif : La Transformation

🟢 Voix Active
Structure

SUJET + verbe + complément

Le chat mange la souris.
Les élèves écrivent la lettre.

✓ Le sujet fait l'action
✓ Construction directe
✓ Forme la plus courante

SUJET + être + participe passé + PAR + AGENT

✓ Auxiliaire "être" + participe
✓ Complément d'agent introduit par "par"

2Qu'est-ce que le complément d'agent ?

Définition complète
Le complément d'agent est un complément du verbe qui indique qui fait l'action dans une phrase à la voix passive. Il correspond au sujet de la phrase active. Il est généralement introduit par les prépositions "par" ou "de".
Analyse détaillée
Voix active : Le professeur explique la leçon.
→ "Le professeur" est le SUJET (fait l'action)
Voix passive : La leçon est expliquée par le professeur.
→ "par le professeur" est le COMPLÉMENT D'AGENT (fait réellement l'action)
Point clé

Le complément d'agent représente l'auteur véritable de l'action dans une phrase passive. C'est lui qui fait réellement l'action exprimée par le verbe !

3Les Prépositions du Complément d'Agent

Deux prépositions possibles
PAR
DE
Utilisation de "PAR" (le plus fréquent)

La préposition "par" est utilisée dans la majorité des cas :

Le gâteau est préparé par ma mère.
La maison a été construite par des architectes.
Les voleurs ont été arrêtés par la police.
Ce roman a été écrit par Victor Hugo.
Les enfants sont surveillés par leurs parents.
Utilisation de "DE" (cas particuliers)

La préposition "de" s'utilise principalement avec :

Verbes de sentiment :
Il est aimé de tous.
Elle est respectée de ses collègues.
Le héros est admiré de la foule.
Verbes d'état ou de qualité :
La ville est entourée de montagnes.
Le jardin est bordé d'arbres.
La table est couverte d'une nappe.

4Quand le complément d'agent est omis

Important à savoir

Le complément d'agent peut être omis dans plusieurs situations. Le passif sans complément d'agent est très fréquent en français !

1. Agent inconnu

On ne sait pas qui a fait l'action :

Ma voiture a été volée.
→ On ne sait pas par qui
La fenêtre a été cassée.
→ L'auteur est inconnu
Un trésor a été découvert.
→ Pas d'agent précisé
2. Agent évident

L'agent est évident par le contexte :

Le suspect a été arrêté.
→ Évidemment par la police
Le patient a été opéré.
→ Évidemment par un chirurgien
La lettre a été envoyée.
→ Agent non pertinent
3. Agent sans importance

L'identité de l'agent n'a pas d'importance :

Le français est parlé au Québec.
→ Agent collectif (les habitants)
Ce livre a été publié en 1990.
→ L'éditeur n'est pas important
La décision a été prise.
→ Pas besoin de préciser par qui
4. Agent = "on" à l'actif

Quand l'agent serait "on" à la voix active :

Actif : On parle français ici.
Passif : Le français est parlé ici.
→ Pas de complément d'agent
Actif : On vend des fleurs.
Passif : Des fleurs sont vendues.
→ Agent omis

5Tableau de Transformation Actif ↔ Passif

Voix Active Voix Passive Complément d'Agent

Les pompiers éteignent l'incendie. L'incendie est éteint par les pompiers. par les pompiers

6Comment Identifier le Complément d'Agent ?

Méthode d'identification
1. Vérifiez que le verbe est à la voix passive (être + participe passé)
2. Cherchez le groupe introduit par "par" ou "de"
3. Posez la question : "Par qui ?" ou "De qui ?"
4. Transformez en voix active : le complément d'agent devient le sujet
Exercice d'identification
Phrase : "Le château a été construit par Louis XIV."

✓ Verbe à la voix passive : "a été construit"
✓ Question : Par qui ? → par Louis XIV
✓ Complément d'agent : par Louis XIV
✓ Transformation active : Louis XIV a construit le château.
Phrase : "Elle est respectée de tous ses collègues."

✓ Verbe à la voix passive : "est respectée"
✓ Question : De qui ? → de tous ses collègues
✓ Complément d'agent : de tous ses collègues
✓ Transformation active : Tous ses collègues la respectent.

7Ne Pas Confondre avec le COI

Attention à la confusion !

Ne confondez pas le complément d'agent avec un complément d'objet indirect (COI) introduit par "par" ou "de" !

Complément d'Agent COI avec "par" ou "de"
Le livre est écrit par l'auteur.
(passif → l'auteur fait l'action)		 Je commence par ce livre.
(actif → "par ce livre" est un COI)
Il est aimé de tous.
(passif → tous l'aiment)		 Je parle de toi.
(actif → "de toi" est un COI)
Voix PASSIVE obligatoire Voix ACTIVE possible
Peut devenir sujet à l'actif Reste complément à l'actif
Points clés à retenir
  • Le complément d'agent indique qui fait l'action dans une phrase passive
  • Il correspond au sujet de la phrase active
  • Il est introduit par "par" (le plus fréquent) ou "de" (cas particuliers)
  • "De" s'utilise avec les verbes de sentiment et d'état
  • Le complément d'agent peut être omis si l'agent est inconnu, évident ou sans importance
  • Pour identifier : cherchez "par qui ?" ou "de qui ?" après un verbe passif
  • Transformation : Complément d'Agent (passif) = Sujet (actif)
  • Ne pas confondre avec un COI introduit par "par" ou "de"
