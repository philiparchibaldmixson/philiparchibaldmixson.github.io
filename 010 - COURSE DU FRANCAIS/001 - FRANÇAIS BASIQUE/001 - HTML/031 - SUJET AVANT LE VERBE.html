🇫🇷 Le Sujet Avant le Verbe

Position Normale et Reprise par un Pronom

📌 Règle Fondamentale

En français, l'ordre normal de la phrase est : SUJET + VERBE + COMPLÉMENTS

Le sujet se place donc avant le verbe, sauf dans certains cas particuliers (questions, inversions stylistiques).

Parfois, pour mettre en valeur le sujet ou créer un effet d'insistance, on utilise une reprise par un pronom.

SUJET → VERBE → COMPLÉMENTS

Position Normale du Sujet

Le Sujet Précède le Verbe

C'est la structure de base de la phrase française :

Marie parle français.
Les enfants jouent dans le jardin.
Mon professeur explique la leçon.
Nous aimons beaucoup ce film.
Le chat dort sur le canapé.

Types de Sujets

Sujet Nom

Pierre travaille ici.
La maison est grande.
Mes amis arrivent demain.

Sujet Pronom

Il travaille ici.
Elle est grande.
Ils arrivent demain.

La Reprise du Sujet par un Pronom

🎯 Qu'est-ce que c'est ?

On reprend le sujet nominal par un pronom personnel pour créer un effet d'emphase ou d'insistance. Cette construction est très courante à l'oral.

SUJET NOM + PRONOM + VERBE

1Reprise Simple du Sujet

Le sujet nominal est repris par un pronom sujet :

Marie, elle parle très bien français.
Mon frère, il habite à Paris.
Les professeurs, ils sont toujours en retard.
Ta sœur, elle a réussi son examen ?
Ces livres, ils coûtent très cher.

Pourquoi utiliser cette structure ?

✓ Pour insister sur le sujet

✓ Pour mettre en valeur qui fait l'action

✓ Style conversationnel et oral

✓ Pour créer un contraste avec d'autres personnes

2Reprise avec Virgule

À l'écrit, on sépare le sujet et le pronom par une virgule :

Paul, il viendra demain.
Cette fille, elle est très intelligente.
Mes parents, ils voyagent beaucoup.

3Reprise pour Contraster

On utilise souvent la reprise pour opposer différents sujets :

Moi, je préfère le thé, mais lui, il aime le café.
Les filles, elles étudient, mais les garçons, ils jouent.
Toi, tu restes ici ; nous, nous partons.

4Reprise Familière (Oral)

À l'oral familier, cette structure est très fréquente :

Ta voiture, elle marche bien ?
Le patron, il a dit quoi ?
Tes amis, ils viennent ce soir ?
Ce film, il est bien ?

Comparaison des Deux Structures

✅ Sans Reprise (Neutre)

Marie parle français.
Les enfants jouent dehors.
Mon frère habite à Lyon.

Usage : Formel, écrit, neutre

💬 Avec Reprise (Emphatique)

Marie, elle parle français.
Les enfants, ils jouent dehors.
Mon frère, il habite à Lyon.

Usage : Oral, familier, emphatique

Attention aux Registres de Langue !

  • 🎓 Registre soutenu/écrit : Évitez la reprise → "Pierre travaille ici."
  • 💼 Registre standard : Reprise acceptable pour l'emphase → "Pierre, il travaille vraiment dur."
  • 💬 Registre familier/oral : Reprise très courante → "Pierre, il est où ?"
  • 📝 Dans un texte formel : N'utilisez pas la reprise, sauf pour un effet stylistique précis

Règles Importantes

  • ✨ Accord du pronom : Le pronom de reprise doit s'accorder en genre et en nombre avec le sujet nominal
  • ✨ Virgule à l'écrit : Toujours mettre une virgule entre le sujet et le pronom de reprise
  • ✨ Position fixe : Le sujet nominal vient toujours en premier, puis le pronom
  • ✨ Emphase : Cette structure met l'accent sur QUI fait l'action
  • ✨ Oral vs Écrit : Beaucoup plus fréquent à l'oral qu'à l'écrit formel
  • ✨ Contraste : Très utile pour opposer différents sujets dans la même phrase

Astuce Pratique

La reprise du sujet par un pronom est comme mettre un projecteur sur le sujet ! C'est dire : "Attention, c'est LUI/ELLE qui fait ça !"

Sans emphase : Pierre a gagné le match.
Avec emphase : Pierre, il a gagné le match ! (sous-entendu : c'est lui et pas un autre)
