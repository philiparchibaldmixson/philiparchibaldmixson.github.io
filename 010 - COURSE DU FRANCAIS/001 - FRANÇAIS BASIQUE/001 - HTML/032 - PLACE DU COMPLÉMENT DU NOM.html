📚 Le Complément du Nom

Place du Complément de Détermination

📌 Qu'est-ce qu'un complément du nom ?

Le complément du nom (aussi appelé complément de détermination) est un mot ou un groupe de mots qui complète et précise le sens d'un nom.

Il permet de donner des informations supplémentaires sur le nom : sa matière, sa provenance, son contenu, son possesseur, etc.

Définition

Le complément du nom est introduit par une préposition (de, à, en, pour, avec, sans, etc.) et se place après le nom qu'il complète.

NOM + PRÉPOSITION + COMPLÉMENT

Position du Complément du Nom

Règle Générale : APRÈS le nom

En français, le complément du nom se place toujours après le nom qu'il complète.

Une tasse de café
La maison de mon ami
Un livre sur l'histoire
Une robe en soie
Le train pour Paris

Erreur Fréquente

❌ INCORRECT : De café une tasse
✅ CORRECT : Une tasse de café

⚠️ Contrairement à certaines langues, le complément ne précède JAMAIS le nom en français !

Les Différents Types de Compléments du Nom

1Matière

Préposition : en, de

Une bague en or
Un mur de pierre
Une table en bois

2Contenu

Préposition : de, à

Un verre de vin
Une tasse de thé
Un sac de bonbons

3Possession

Préposition : de

Le livre de Marie
La voiture de mon père
Les jouets des enfants

4Provenance

Préposition : de

Les vins de France
Un fromage de Normandie
L'équipe de Marseille

5Destination

Préposition : pour, à

Un billet pour Lyon
Une machine à laver
Un cadeau pour maman

6Sujet/Thème

Préposition : sur, de

Un livre sur la géographie
Une conférence sur l'art
L'histoire de France

Prépositions les Plus Courantes

Les Prépositions du Complément du Nom

DE : la plus fréquente → un moment de repos, le livre de Pierre
À : destination, caractéristique → une machine à laver, un moulin à vent
EN : matière → une statue en bronze, un pull en laine
POUR : destination → un train pour Rome, un cadeau pour toi
AVEC : accompagnement → un café avec du sucre, une chambre avec vue
SANS : absence → un café sans sucre, une vie sans soucis
CONTRE : opposition → la lutte contre le cancer
SUR : thème → un débat sur l'écologie

Compléments du Nom Multiples

Un nom peut avoir plusieurs compléments

Quand un nom a plusieurs compléments, ils se placent tous après le nom, l'un après l'autre :

La maison de mon oncle à la campagne
Un livre d'histoire pour enfants
Une tasse de café avec du lait
Le train de Paris pour Lyon

Différence avec l'Adjectif

📘 Adjectif

Position variable

Une belle maison
(avant le nom)
Une maison blanche
(après le nom)

Pas de préposition

📗 Complément du Nom

Toujours après

Une maison de campagne
(après le nom)
Une maison en pierre
(après le nom)

Toujours une préposition

Astuce pour Reconnaître

Si vous voyez une préposition (de, à, en, pour...) après le nom, c'est un complément du nom !

• Une table rouge → adjectif (pas de préposition)
• Une table en bois → complément du nom (préposition "en")

Règles Importantes

  • ✨ Position fixe : Le complément du nom se place TOUJOURS après le nom qu'il complète
  • ✨ Préposition obligatoire : Le complément est introduit par une préposition (de, à, en, pour, etc.)
  • ✨ Accord : Le complément du nom ne s'accorde PAS avec le nom (sauf s'il est un nom lui-même)
  • ✨ Multiples compléments : Un nom peut avoir plusieurs compléments successifs
  • ✨ Fonction : Le complément précise le sens du nom (matière, contenu, possession, etc.)
  • ✨ Invariable : La préposition reste invariable, elle ne change jamais

Exemples dans des Phrases Complètes

J'ai acheté une robe en soie dans la boutique du quartier.
Le professeur de mathématiques nous a donné un devoir pour demain.
Elle boit toujours un verre d'eau avec du citron le matin.
Les clés de la voiture sont sur la table du salon.
Nous avons visité le musée d'art moderne de Paris.

Conseil Pratique

Pour bien identifier un complément du nom, posez-vous la question :

« Quel type de [nom] ? »

• Une tasse de café → Quel type de tasse ? Une tasse DE CAFÉ
• Une robe en soie → Quel type de robe ? Une robe EN SOIE
• Le livre de Marie → Quel livre ? Le livre DE MARIE
