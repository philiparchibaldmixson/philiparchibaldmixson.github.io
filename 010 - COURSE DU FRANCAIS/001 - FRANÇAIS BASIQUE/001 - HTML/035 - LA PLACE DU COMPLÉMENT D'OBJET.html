🇫🇷 La Place du Complément d'Objet

Où Placer le COD et le COI dans la Phrase ?

📍 Question Fondamentale

Où placer le complément d'objet dans une phrase française ? La position du COD et du COI varie selon plusieurs facteurs : est-ce un nom ou un pronom ? Quel est le temps du verbe ? Y a-t-il un infinitif ?

Cette leçon explique toutes les règles de placement du complément d'objet.

Règle Générale : Après le Verbe

1📌Position Normale du COD et COI

SUJET + VERBE + COMPLÉMENT

Règle générale : Le complément d'objet (COD ou COI) se place après le verbe quand c'est un nom ou un groupe nominal.

Exemples avec COD nominal :

Je lis un livre.
Marie mange une pomme.
Nous regardons la télévision.
Les enfants écoutent de la musique.

Exemples avec COI nominal :

Je parle à Marie.
Paul téléphone à ses parents.
Elle pense à son voyage.
Nous obéissons au professeur.

Place du Complément Pronominal

2🔄Pronoms Compléments : AVANT le Verbe

SUJET + PRONOM + VERBE

Règle importante : Quand le complément est un pronom (le, la, les, lui, leur, me, te, nous, vous...), il se place AVANT le verbe.

Les Pronoms Compléments

COD : me, te, le, la, nous, vous, les
COI : me, te, lui, nous, vous, leur
Réfléchis : me, te, se, nous, vous, se
Neutres : en, y

Transformation : Nom → Pronom

Avec Nom (après)

Je lis un livre.
Je vois Marie.
Je parle à Pierre.

Avec Pronom (avant)

Je le lis.
Je la vois.
Je lui parle.

Exemples avec pronoms COD :

Je le vois.
Tu la connais ?
Nous les regardons.
Elle me voit.

Exemples avec pronoms COI :

Je lui parle.
Tu leur téléphones.
Elle nous écrit.
Il vous répond.

Place avec les Temps Composés

3⏰Passé Composé et Autres Temps Composés

Avec nom : AUXILIAIRE + PARTICIPE + NOM
Avec pronom : PRONOM + AUXILIAIRE + PARTICIPE

COD nominal : après le participe passé

J'ai lu un livre.
Elle a mangé une pomme.
Nous avons vu le film.

COD pronominal : avant l'auxiliaire

Je l'ai lu.
Elle l'a mangée.
Nous l'avons vu.
Je les ai vus.

Accord du Participe Passé

Quand le COD pronom est placé avant l'auxiliaire avoir, le participe passé s'accorde avec lui !

Les pommes ? Je les ai mangées. (accord avec "les" = féminin pluriel)

Place avec un Infinitif

4∞Verbe + Infinitif

Avec nom : VERBE + INFINITIF + NOM
Avec pronom : VERBE + PRONOM + INFINITIF

Avec une construction verbe + infinitif, le pronom complément se place avant l'infinitif (et non avant le premier verbe).

COD nominal : après l'infinitif

Je veux lire ce livre.
Elle va manger une pizza.
Tu peux voir le tableau.

COD pronominal : avant l'infinitif

Je veux le lire.
Elle va la manger.
Tu peux le voir.
Nous allons les acheter.

Erreur Fréquente !

❌ Je le veux lire.
✅ Je veux le lire.

Le pronom se place avant l'infinitif, pas avant le verbe conjugué !

Place à l'Impératif

5❗Impératif : Cas Particulier

Impératif affirmatif : VERBE + PRONOM
Impératif négatif : PRONOM + VERBE

Impératif AFFIRMATIF : pronom APRÈS

Regarde-le !
Mange-la !
Écoute-moi !
Donne-leur ce livre !

Impératif NÉGATIF : pronom AVANT

Ne le regarde pas !
Ne la mange pas !
Ne me parle pas !
Ne leur donne pas ce livre !

Attention aux Formes !

À l'impératif affirmatif, certains pronoms changent de forme :

me → moi : Écoute-moi !
te → toi : Lève-toi !

Tableau Récapitulatif

Présent Simple

Nom : Je lis un livre.
Pronom : Je le lis.

Passé Composé

Nom : J'ai lu un livre.
Pronom : Je l'ai lu.

Verbe + Infinitif

Nom : Je veux lire un livre.
Pronom : Je veux le lire.

Impératif +

Lis-le !
Mange-la !

Impératif -

Ne le lis pas !
Ne la mange pas !

Règles Essentielles à Retenir

  • 📍 COD/COI nominal : Toujours APRÈS le verbe (ou après le participe/infinitif)
  • 📍 COD/COI pronominal : AVANT le verbe conjugué (sauf impératif affirmatif)
  • 📍 Temps composés : Pronom avant l'auxiliaire → Accord du participe passé avec COD
  • 📍 Verbe + infinitif : Pronom avant l'INFINITIF (pas avant le verbe conjugué)
  • 📍 Impératif affirmatif : Pronom APRÈS le verbe avec trait d'union
  • 📍 Impératif négatif : Pronom AVANT le verbe comme d'habitude
  • 📍 Ordre COD + COI : Quand il y a deux pronoms, suivre l'ordre : me/te/se/nous/vous + le/la/les + lui/leur

Astuce Pratique

La règle d'or :

✨ NOM = APRÈS le verbe
✨ PRONOM = AVANT le verbe

Exception : Impératif affirmatif → pronom après le verbe

Deux Pronoms Ensemble

Quand il y a COD + COI pronominaux, l'ordre est précis :

Je donne le livre à Marie → Je le lui donne.
Il montre les photos à nous → Il nous les montre.

Ordre : me/te/nous/vous → le/la/les → lui/leur
