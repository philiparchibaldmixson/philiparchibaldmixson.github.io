🇫🇷 Le Nom Attribut

Attribut du Sujet et Attribut du COD

🎯 Qu'est-ce qu'un attribut ?

L'attribut est un mot ou un groupe de mots qui exprime une qualité, une caractéristique ou une manière d'être attribuée au sujet (ou au COD).

Quand l'attribut est un nom, on l'appelle nom attribut. Il se distingue de l'adjectif attribut.

Le Nom Attribut du Sujet

Définition

Le nom attribut du sujet est un nom qui caractérise ou identifie le sujet par l'intermédiaire d'un verbe d'état (être, paraître, sembler, devenir, rester, etc.).

Il fait partie du groupe verbal et ne peut pas être supprimé sans rendre la phrase incorrecte.

SUJET + VERBE D'ÉTAT + NOM ATTRIBUT

1✨Structure avec Verbe ÊTRE

Le verbe être est le verbe d'état le plus courant. Il établit une égalité ou une identification entre le sujet et l'attribut.

Pierre est médecin.
Pierre est quoi ? → médecin (nom attribut du sujet)
Marie est professeure.
Mon père est ingénieur.
Cette ville est la capitale.
Le chat est un animal domestique.
Paris est la ville lumière.

2🔄Avec Autres Verbes d'État

D'autres verbes peuvent introduire un nom attribut : devenir, rester, demeurer, paraître, sembler, avoir l'air, passer pour, etc.

Il est devenu président.
Le verbe "devenir" introduit le nom attribut "président"
Elle reste ma meilleure amie.
Tu sembles un bon élève.
Nous demeurons des citoyens responsables.
Elle a l'air d'une princesse.
Il passe pour un expert.

Le Nom Attribut du COD

Définition

Le nom attribut du COD est un nom qui caractérise le complément d'objet direct. Il est introduit par certains verbes comme appeler, nommer, élire, juger, estimer, trouver, rendre, etc.

Structure : SUJET + VERBE + COD + NOM ATTRIBUT DU COD

SUJET + VERBE + COD + ATTRIBUT DU COD

3👑Verbes avec Attribut du COD

On a élu Pierre président.
On a élu Pierre (COD) quoi ? → président (attribut du COD Pierre)
Ils ont nommé Marie directrice.
Je trouve cette solution un miracle.
On l'appelle le roi des forêts.
Nous considérons Paul un ami.
Elle traite son chien un membre de la famille.

Caractéristiques du Nom Attribut

4📋Propriétés Importantes

  • 🔹 Ne peut pas être supprimé : L'attribut fait partie intégrante du groupe verbal
  • 🔹 Caractérise le sujet ou le COD : Il exprime une qualité, une identité, une fonction
  • 🔹 Introduit par un verbe d'état : être, devenir, paraître, sembler, rester, etc.
  • 🔹 Peut être précédé d'un article : Il est médecin / Il est un médecin réputé
  • 🔹 Accord possible : Selon le contexte, peut s'accorder avec le sujet/COD

✅ Phrase Correcte

Pierre est médecin.

L'attribut "médecin" est nécessaire pour donner un sens à la phrase.

❌ Phrase Incorrecte

Pierre est. ❌

Sans attribut, la phrase n'a pas de sens complet.

Nom Attribut vs Autres Fonctions

Nom Attribut

Pierre est médecin.

• Avec verbe d'état
• Caractérise le sujet
• Ne peut être supprimé

COD

Pierre voit le médecin.

• Avec verbe d'action
• Complète le verbe
• Répond à "quoi ?"

Apposition

Pierre, médecin, travaille ici.

• Sans verbe
• Entre virgules
• Peut être supprimé

Accord du Nom Attribut

5⚖️Règles d'Accord

Accord en genre :

Marie est médecin. (ou médecine)
Elle est professeure. (féminin de professeur)
Sophie est devenue directrice.

Accord en nombre :

Ils sont médecins.
Elles sont professeures.
Mes amis sont devenus ingénieurs.

Note Importante

L'accord du nom attribut dépend du contexte :

• Certains noms de profession s'accordent : professeur → professeure
• D'autres restent invariables : médecin (pour les deux genres)
• En nombre, l'accord se fait généralement avec le sujet

Comment Identifier un Nom Attribut ?

Tests d'Identification

  • Test 1 : Chercher le verbe d'état
    Y a-t-il un verbe comme être, devenir, paraître, sembler, rester ?
  • Test 2 : Question "Qu'est-ce que... ?"
    Pierre est médecin → Qu'est-ce que Pierre ? → médecin (attribut)
  • Test 3 : Peut-on supprimer ?
    Si non, c'est probablement un attribut (partie essentielle)
  • Test 4 : Remplacer par un adjectif
    Pierre est médecin → Pierre est intelligent (attribut aussi)

Exemples Récapitulatifs

Attribut du Sujet :

Mon frère est avocat.
Cette femme est devenue une star.
Il reste mon meilleur ami.
Paris demeure la capitale de la mode.

Attribut du COD :

On a élu Marie présidente.
Je trouve cette idée une solution brillante.
Tout le monde l'appelle le champion.
Nous considérons Paul un expert.

Astuce Pratique

Pour reconnaître un nom attribut :

✨ Cherchez un verbe d'état (être, devenir, paraître...)
✨ Le nom après ce verbe caractérise le sujet
✨ Il ne peut pas être supprimé sans détruire le sens
✨ Il fait partie du groupe verbal
