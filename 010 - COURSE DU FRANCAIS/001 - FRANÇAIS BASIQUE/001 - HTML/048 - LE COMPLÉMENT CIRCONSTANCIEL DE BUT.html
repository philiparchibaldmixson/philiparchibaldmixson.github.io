Le Complément Circonstanciel de But

🎯 Pour quoi faire ? Dans quel but ? Afin de quoi ? 🎯

Qu'est-ce qu'un CC de But ?

Le complément circonstanciel de but (CC de but) est un complément de phrase qui indique l'objectif, l'intention, la finalité de l'action exprimée par le verbe. Il exprime ce qu'on veut obtenir, atteindre ou éviter.

🎯 Définition : Le CC de but précise l'intention, l'objectif visé par l'action. Il répond aux questions : Pour quoi faire ? Dans quel but ? Afin de quoi ? Pour quelle finalité ? En vue de quoi ? Dans quelle intention ?

Le CC de but exprime toujours une action future ou potentielle par rapport à l'action principale. C'est ce qu'on cherche à réaliser, à obtenir ou à éviter.

Le CC de but est généralement supprimable et déplaçable dans la phrase.

❓ Les Questions pour Identifier le CC de But

🎯 Pour quoi faire ? / Dans quel but ?
La question la plus courante pour identifier le CC de but :

• Il travaille pour réussir. → Pour quoi faire travaille-t-il ?
• Je pars afin de te voir. → Dans quel but pars-tu ?
• Elle étudie en vue de l'examen. → En vue de quoi étudie-t-elle ?
• Nous économisons pour acheter une maison. → Pour quoi faire ?
🎓 Afin de quoi ? / En vue de quoi ?
Pour exprimer une finalité précise :

• Il s'entraîne afin de gagner. → Afin de quoi s'entraîne-t-il ?
• Elle se prépare en vue du concours. → En vue de quoi se prépare-t-elle ?
• Ils travaillent dans le but de réussir. → Dans quel but travaillent-ils ?
🚫 Pour éviter quoi ? / De peur de quoi ?
Pour un but négatif (éviter quelque chose) :

• Il se cache de peur d'être vu. → De peur de quoi ?
• Elle court de crainte d'arriver en retard. → De crainte de quoi ?
• Nous partons tôt pour éviter les embouteillages. → Pour éviter quoi ?

🏗️ Constructions du CC de But

1️⃣ Infinitif avec Préposition Très fréquent

Le CC de but est très souvent exprimé par un infinitif précédé d'une préposition (pour, afin de, de peur de, de crainte de, en vue de, dans le but de, etc.).
POUR + infinitif (le plus courant) :
Il travaille pour réussir • Elle étudie pour apprendre • Nous économisons pour acheter une maison
AFIN DE + infinitif (plus soutenu) :
Je pars tôt afin d'arriver à l'heure • Il s'entraîne afin de gagner
DE PEUR DE + infinitif (but négatif) :
Il se cache de peur d'être vu • Elle se tait de peur de dire une bêtise
DE CRAINTE DE + infinitif (but négatif) :
Il court de crainte d'arriver en retard • Elle vérifie tout de crainte d'oublier quelque chose
EN VUE DE + infinitif (finalité précise) :
Elle s'entraîne en vue de la compétition • Ils se préparent en vue de partir
DANS LE BUT DE + infinitif (formel) :
Nous agissons dans le but de trouver une solution

2️⃣ Proposition Subordonnée Conjonctive Très courant

Le CC de but peut être une proposition subordonnée introduite par une conjonction de subordination (pour que, afin que, de peur que, de crainte que, de sorte que, etc.) suivie du subjonctif.
POUR QUE + subjonctif (le plus courant) :
Je t'explique pour que tu comprennes • Il parle fort pour qu'on l'entende
AFIN QUE + subjonctif (plus soutenu) :
Elle part tôt afin qu'il puisse arriver à l'heure • Nous agissons afin que tout soit prêt
DE PEUR QUE + NE + subjonctif (but négatif) :
Il se cache de peur qu'on ne le voie • Elle se tait de peur qu'il ne se fâche
DE CRAINTE QUE + NE + subjonctif (but négatif) :
Je ferme la porte de crainte qu'il ne fasse froid
DE SORTE QUE + subjonctif (conséquence voulue) :
Parle clairement de sorte qu'on te comprenne

3️⃣ Groupe Nominal avec Préposition Courant

Le CC de but peut être un groupe nominal précédé d'une préposition ou locution prépositionnelle (pour, en vue de, dans le but de, en prévision de, etc.).
POUR + nom :
Il travaille pour la réussite • Elle lutte pour la liberté
EN VUE DE + nom :
Elle se prépare en vue de l'examen • Ils économisent en vue du voyage
DANS LE BUT DE + nom :
Nous agissons dans le but d'une amélioration
EN PRÉVISION DE + nom :
Il fait des réserves en prévision de l'hiver

4️⃣ Adverbe ou Locution Adverbiale Moins fréquent

Certains adverbes ou locutions peuvent exprimer le but, bien que ce soit rare.
Il agit intentionnellement (= dans l'intention de...) • Elle fait ça exprès (= dans le but de...)

5️⃣ Relative de But Rare, style soutenu

Une proposition relative peut exprimer le but avec "où" + subjonctif (style littéraire).
Je cherche un endroit où je puisse travailler (= pour y travailler)

🔑 Prépositions et Locutions de But

Préposition la plus courante pour exprimer le but. Suivie d'un infinitif ou d'un nom.
  • Il travaille pour réussir
  • Elle étudie pour l'examen
  • Nous économisons pour acheter une maison
  • Je pars pour te voir
📚 AFIN DE
Plus soutenu que "pour". Exprime une finalité précise. Suivi d'un infinitif.
  • Je pars tôt afin d'arriver à l'heure
  • Il s'entraîne afin de gagner
  • Elle révise afin de réussir
😰 DE PEUR DE
Exprime un but négatif : éviter quelque chose de désagréable. Suivi d'un infinitif.
  • Il se cache de peur d'être vu
  • Elle se tait de peur de dire une bêtise
  • Je pars de peur d'être en retard
😨 DE CRAINTE DE
Synonyme plus soutenu de "de peur de". Exprime la crainte. Suivi d'un infinitif.
  • Il court de crainte d'arriver en retard
  • Elle vérifie tout de crainte d'oublier
  • Je me dépêche de crainte de manquer le train
👁️ EN VUE DE
Exprime une finalité précise, un objectif clair. Suivi d'un infinitif ou d'un nom.
  • Elle s'entraîne en vue de la compétition
  • Il se prépare en vue de partir
  • Nous étudions en vue de l'examen
🎓 DANS LE BUT DE
Expression formelle pour le but. Suivi d'un infinitif ou d'un nom.
  • Nous agissons dans le but de trouver une solution
  • Il travaille dans le but de réussir
  • Elle étudie dans le but d'apprendre
📅 EN PRÉVISION DE
Exprime un but en se préparant à l'avance. Suivi d'un nom.
  • Il fait des réserves en prévision de l'hiver
  • Nous nous préparons en prévision de la tempête
  • Elle économise en prévision de ses études
⚠️ HISTOIRE DE
Familier, exprime un but simple, sans grande importance. Suivi d'un infinitif.
  • Il passe histoire de dire bonjour
  • Je regarde histoire de voir
  • Elle appelle histoire de prendre des nouvelles

⚖️ Distinctions Importantes

🎯 CC de But
Pour quoi faire ? Dans quelle intention ?

Exprime l'objectif, l'intention (action future/potentielle).

Exemples :
• "Il travaille pour réussir" (but)
→ Pour quoi faire ? Pour réussir (intention)

• "Je pars afin de te voir" (but)
→ Dans quel but ? Pour te voir (objectif)

➡️ Indique l'intention, l'objectif 🎯
🔍 CC de Cause
Pourquoi ? Pour quelle raison ?

Explique la raison, l'origine (action passée/présente).

Exemples :
• "Il est puni pour avoir menti" (cause)
→ Pourquoi est-il puni ? Parce qu'il a menti (raison)

• "Je pars parce qu'il pleut" (cause)
→ Pourquoi pars-je ? Parce qu'il pleut (raison)

➡️ Explique la raison 🔍
💫 CC de Conséquence
Quel résultat ? Quelle conséquence ?

Exprime le résultat, l'effet obtenu.

Exemples :
• "Il travaille dur, si bien qu'il réussit" (conséquence)
→ Quel résultat ? Il réussit (effet obtenu)

• "Il pleut, donc je reste" (conséquence)
→ Résultat de la pluie : je reste

➡️ Exprime le résultat 💫

📌 Règle de Distinction Rapide

BUT → Exprime l'intention (ce qu'on veut obtenir) 🎯
"Il travaille pour réussir" (objectif futur : la réussite)

CAUSE → Explique la raison (pourquoi ça arrive) 🔍
"Il est puni pour avoir menti" (raison passée : le mensonge)

CONSÉQUENCE → Exprime le résultat (ce qui se passe) 💫
"Il travaille dur, si bien qu'il réussit" (résultat obtenu : la réussite)

📊 Tableau : POUR + infinitif (But vs Cause)

Expression Sens Temps Exemple
POUR + infinitif présent BUT (intention) Action future Il travaille pour réussir
POUR + infinitif passé CAUSE (raison) Action passée Il est puni pour avoir menti
POUR QUE + subjonctif BUT (intention) Action future Je t'aide pour que tu réussisses
DE PEUR DE + infinitif BUT négatif (éviter) Action à éviter Il se cache de peur d'être vu
AFIN DE + infinitif BUT (finalité) Action future Je pars tôt afin d'arriver à l'heure

💡 Conseils pour Identifier le CC de But

❓ Posez "Pour quoi faire ?"

Pour identifier un CC de but, posez la question "Pour quoi faire ?", "Dans quel but ?" ou "Afin de quoi ?"

🔍 Cherchez "pour" et "afin de"

Les expressions "pour", "afin de", "en vue de", "dans le but de" introduisent presque toujours un CC de but.

🎯 Le but = intention future

Le but exprime toujours une intention, un objectif futur ou potentiel par rapport à l'action principale.

📚 Attention au subjonctif

Les conjonctions de but (pour que, afin que, de peur que) sont TOUJOURS suivies du subjonctif.

⚖️ BUT vs CAUSE avec "POUR"

POUR + infinitif présent = BUT ✅
POUR + infinitif passé = CAUSE
"Il travaille pour réussir" (but) ≠ "Il est puni pour avoir menti" (cause)

✂️ Testez la suppression

Le CC de but est généralement supprimable : "Il travaille pour réussir" → "Il travaille" ✅

🎯 Points Importants à Retenir

✅ Le CC de but exprime l'intention, l'objectif :
• Il répond à "Pour quoi faire ?", "Dans quel but ?", "Afin de quoi ?"
• Le but est toujours une action future ou potentielle

✅ Principales prépositions de but :
• POUR : la plus courante (pour + infinitif/nom)
• AFIN DE : plus soutenu (afin de + infinitif)
• DE PEUR DE / DE CRAINTE DE : but négatif (éviter quelque chose)
• EN VUE DE : finalité précise (en vue de + infinitif/nom)
• DANS LE BUT DE : formel (dans le but de + infinitif)

✅ Principales conjonctions de but :
• POUR QUE + subjonctif : la plus courante
• AFIN QUE + subjonctif : plus soutenu
• DE PEUR QUE + NE + subjonctif : but négatif
• DE CRAINTE QUE + NE + subjonctif : but négatif
• Toutes les conjonctions de but sont suivies du SUBJONCTIF

✅ Distinction BUT vs CAUSE vs CONSÉQUENCE :
• BUT : intention (ce qu'on veut obtenir) → "Il travaille pour réussir"
• CAUSE : raison (pourquoi ça arrive) → "Il est puni pour avoir menti"
• CONSÉQUENCE : résultat (ce qui se passe) → "Il travaille, si bien qu'il réussit"

✅ Règle importante avec "POUR" :
• POUR + infinitif présent = BUT (action future)
• POUR + infinitif passé = CAUSE (action passée)
• "pour réussir" (but) ≠ "pour avoir réussi" (cause)

✅ Le "NE" explétif avec DE PEUR QUE / DE CRAINTE QUE :
• On ajoute "ne" (sans valeur négative) après ces conjonctions
• "Il se cache de peur qu'on ne le voie" (≠ ne... pas)

✅ Le CC de but est supprimable et déplaçable :
• "Il travaille pour réussir" → "Il travaille" (suppression) ✅
• "Pour réussir, il travaille" (déplacement) ✅

Maîtrisez le complément circonstanciel de but pour exprimer vos intentions et objectifs avec précision ! 🇫🇷 🎯
