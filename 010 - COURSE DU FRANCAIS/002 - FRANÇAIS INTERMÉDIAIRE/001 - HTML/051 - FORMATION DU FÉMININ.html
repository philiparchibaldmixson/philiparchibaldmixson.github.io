🌸 Formation du Féminin

Les Adjectifs Qualificatifs en Français

📖 Introduction

En français, l'adjectif qualificatif s'accorde en genre avec le nom qu'il qualifie. Pour former le féminin d'un adjectif, il existe plusieurs règles selon la terminaison de l'adjectif au masculin. Découvrons ensemble toutes ces règles de transformation !

1
Règle Générale : Ajout du -e
Règle : On ajoute simplement un -e à la fin de l'adjectif masculin pour former le féminin.
grand
→
grande
fort
→
forte
petit
→
petite
bleu
→
bleue
français
→
française
amusant
→
amusante
2
Adjectifs terminés par -e
Règle : Les adjectifs qui se terminent déjà par -e au masculin ne changent pas au féminin.
jeune
→
jeune
rouge
→
rouge
rapide
→
rapide
calme
→
calme
large
→
large
sage
→
sage
3
Doublement de la consonne finale + e
Règle : Certains adjectifs doublent leur consonne finale avant d'ajouter le -e.
Terminaison Masculin Féminin
-el → -elle cruel cruelle
-eil → -eille pareil pareille
-en → -enne ancien ancienne
-on → -onne bon bonne
-et → -ette muet muette
-s → -sse gros grosse
traditionnel
→
traditionnelle
européen
→
européenne
mignon
→
mignonne
coquet
→
coquette

⚠️ Exceptions importantes :

complet → complète
secret → secrète
discret → discrète
concret → concrète
inquiet → inquiète
4
Adjectifs en -er → -ère
Règle : Les adjectifs terminés par -er prennent un accent grave sur le e : -ère
léger
→
légère
fier
→
fière
cher
→
chère
premier
→
première
dernier
→
dernière
étranger
→
étrangère
5
Adjectifs en -eux → -euse
Règle : Les adjectifs en -eux deviennent -euse
heureux
→
heureuse
joyeux
→
joyeuse
peureux
→
peureuse
sérieux
→
sérieuse
dangereux
→
dangereuse
courageux
→
courageuse
6
Adjectifs en -f → -ve
Règle : Les adjectifs en -f deviennent -ve
vif
→
vive
neuf
→
neuve
actif
→
active
sportif
→
sportive
attentif
→
attentive
créatif
→
créative
7
Adjectifs en -c → -che ou -que
Règle : Les adjectifs en -c ont deux transformations possibles
Transformation Masculin Féminin
-c → -che blanc blanche
-c → -che franc franche
-c → -che sec sèche
-c → -que public publique
-c → -que turc turque
-c → -que grec grecque
8
Adjectifs en -x → -se
Règle : Les adjectifs en -x deviennent généralement -se
jaloux
→
jalouse
doux
→
douce
roux
→
rousse
faux
→
fausse

💡 Attention !

Les adjectifs en -eux suivent la règle vue précédemment : -eux → -euse

9
Cas Particuliers et Irréguliers
Attention : Certains adjectifs ont des formes complètement irrégulières au féminin
Masculin Féminin Particularité
beau belle Forme irrégulière
nouveau nouvelle Forme irrégulière
vieux vieille Forme irrégulière
fou folle Forme irrégulière
mou molle Forme irrégulière
gentil gentille Doublement du l
long longue Ajout d'un u
favori favorite Changement complet
frais fraîche Changement avec accent
malin maligne Forme irrégulière

🎯 Formes spéciales devant voyelle :

Certains adjectifs masculins ont une forme spéciale devant un nom commençant par une voyelle ou un h muet :

beau → un bel homme
nouveau → un nouvel ami
vieux → un vieil arbre
fou → un fol espoir
mou → un mol oreiller

✨ Astuce mémorisation

Pour retenir les règles :

  • La plupart des adjectifs suivent la règle générale : + e
  • Mémorisez les terminaisons qui doublent : -el, -en, -on, -et, -s
  • Retenez les transformations : -er → -ère, -eux → -euse, -f → -ve
  • Apprenez par cœur les irréguliers les plus courants : beau/belle, nouveau/nouvelle, vieux/vieille
