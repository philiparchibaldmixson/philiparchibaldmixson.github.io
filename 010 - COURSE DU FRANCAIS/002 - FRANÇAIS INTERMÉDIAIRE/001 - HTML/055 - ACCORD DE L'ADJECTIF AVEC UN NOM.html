L'Accord de l'Adjectif

Avec un Nom Suivi d'un Complément

Principe Général

Lorsqu'un adjectif qualifie un groupe nominal composé d'un nom principal suivi d'un complément (souvent introduit par « de », « en », « à »), l'accord de l'adjectif dépend du sens : qualifie-t-il le nom principal ou le complément ? C'est une question de logique et de sens !

La Question Clé

Demandez-vous : « Qu'est-ce qui est qualifié par l'adjectif ? »
Le mot qui porte la qualité exprimée par l'adjectif détermine l'accord.

Cas 1 : L'Adjectif Qualifie le Nom Principal

Accord avec le Nom Principal

L'adjectif s'accorde avec le nom principal quand c'est lui qui possède la qualité.

Un verre de vin plein
→ C'est le verre qui est plein
Une tasse de café vide
→ C'est la tasse qui est vide
Un groupe d'étudiants nombreux
→ C'est le groupe qui est nombreux
Une foule de manifestants impressionnante
→ C'est la foule qui est impressionnante

Cas 2 : L'Adjectif Qualifie le Complément

Accord avec le Complément

L'adjectif s'accorde avec le complément quand c'est lui qui possède la qualité.

Un verre de vin rouge
→ C'est le vin qui est rouge
Une tasse de café chaud
→ C'est le café qui est chaud
Un groupe d'étudiants motivés
→ Ce sont les étudiants qui sont motivés
Une foule de manifestants pacifiques
→ Ce sont les manifestants qui sont pacifiques

Comparaison des Deux Accords

📌 Accord avec le Nom Principal

Un paquet de bonbons fermé
(le paquet est fermé)
Une boîte de chocolats ouverte
(la boîte est ouverte)
Un tas de pierres énorme
(le tas est énorme)

📌 Accord avec le Complément

Un paquet de bonbons colorés
(les bonbons sont colorés)
Une boîte de chocolats fins
(les chocolats sont fins)
Un tas de pierres blanches
(les pierres sont blanches)

Cas Particuliers

Noms de Mesure ou de Contenance

Avec les noms indiquant une mesure, l'accord suit la logique du sens.

Un kilo de pommes rouges (les pommes sont rouges)
Une bouteille de vin excellent (le vin est excellent)
Un litre de lait frais (le lait est frais)
Deux mètres de tissu bleu (le tissu est bleu)
Noms Collectifs (groupe, foule, multitude, etc.)

L'accord peut se faire avec le nom collectif (singulier) ou le complément (pluriel) selon le sens.

Une multitude de personnes intéressée (la multitude est intéressée)
Une multitude de personnes intéressées (les personnes sont intéressées)
Les deux sont corrects ! Cela dépend de ce que vous voulez mettre en valeur.
Expressions Figées

Certaines expressions ont un accord fixe, indépendant du sens logique.

Un chef-d'œuvre de précision (toujours singulier)
Une merveille d'architecture (toujours singulier)
Un acte de courage (toujours singulier)

Méthode de Décision

Arbre de Décision
1️⃣ Identifiez le groupe nominal Repérez le nom principal et son complément
Exemple : Un verre [nom principal] de vin [complément]
2️⃣ Posez la question de sens « Qu'est-ce qui possède la qualité exprimée par l'adjectif ? »
Exemple : Qu'est-ce qui est rouge ? → Le vin
3️⃣ Accordez avec le mot qualifié Faites l'accord en genre et en nombre avec le mot qui porte la qualité
Exemple : Un verre de vin rouge (masculin singulier comme « vin »)

Exemples Variés

Avec différentes prépositions :

Avec « de » :
• Un sac de bonbons délicieux
• Une collection de livres anciens
• Un bouquet de roses magnifiques
Avec « en » :
• Une statue en marbre imposante
• Un meuble en bois solide
Avec « à » :
• Une robe à fleurs élégante
• Un gâteau aux fruits délicieux

Astuce pratique : Si vous hésitez, reformulez la phrase pour identifier clairement ce qui est qualifié. Par exemple : « Un verre de vin rouge » → « Le vin est rouge » ou « Le verre est rouge » ? La réponse évidente vous indiquera l'accord correct !

Conseil Final

L'accord de l'adjectif avec un nom suivi d'un complément n'est pas une question de règle rigide, mais de compréhension du sens. Entraînez-vous à vous poser systématiquement la question : « Quel mot porte vraiment la qualité ? » et l'accord deviendra naturel ! 🎯
