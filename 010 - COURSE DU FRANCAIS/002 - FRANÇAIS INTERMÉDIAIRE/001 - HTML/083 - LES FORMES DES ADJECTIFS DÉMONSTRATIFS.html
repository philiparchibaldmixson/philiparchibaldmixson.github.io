📖 Qu'est-ce qu'un Adjectif Démonstratif ?

L'adjectif démonstratif est un déterminant qui sert à montrer, à désigner une personne ou une chose dans l'espace ou dans le temps. Il accompagne toujours un nom et s'accorde avec lui en genre et en nombre.

Fonction Principale

  • Montrer une personne ou une chose : Ce livre est intéressant
  • Désigner quelque chose de proche ou d'éloigné : Cette maison-ci, cet arbre-là
  • Reprendre un élément déjà mentionné : J'ai lu un roman. Ce roman était captivant.
  • Situer dans le temps : Cette année, ce mois-ci

Différence Fondamentale

Ne confondez pas l'adjectif démonstratif (ce, cet, cette, ces) avec le pronom démonstratif (celui, celle, ceux, celles) qui remplace le nom au lieu de l'accompagner.

• Adjectif : Ce livre (accompagne le nom)

• Pronom : Celui-ci (remplace le nom)

🎯 Les Formes de Base

L'adjectif démonstratif a quatre formes de base selon le genre et le nombre du nom qu'il accompagne. Une forme particulière existe pour le masculin singulier devant voyelle ou h muet.

Présentation Détaillée des Formes

CE
Masculin Singulier + Consonne

Ce livre est passionnant.

Ce garçon joue au football.

Ce tableau est magnifique.

Ce professeur est compétent.

Ce héros (h aspiré) est courageux.

CET
Masculin Singulier + Voyelle / H muet

Cet ami est fidèle.

Cet homme travaille dur.

Cet arbre est centenaire.

Cet oiseau chante bien.

Cet ordinateur est rapide.

CETTE
Féminin Singulier

Cette maison est belle.

Cette femme est élégante.

Cette voiture est neuve.

Cette idée est intéressante.

Cette histoire est vraie.

CES
Pluriel (Masculin et Féminin)

Ces livres sont neufs.

Ces maisons sont anciennes.

Ces enfants sont sages.

Ces fleurs sont parfumées.

Ces étudiants travaillent bien.

📏 Règles d'Utilisation : CE ou CET ?

La Règle d'Euphonie

Règle Fondamentale

Devant un nom masculin singulier commençant par une voyelle ou un h muet, on utilise CET au lieu de CE pour faciliter la prononciation et éviter l'hiatus (choc de deux voyelles).

Utilisation de CE

  • Ce livre (consonne)
  • Ce professeur (consonne)
  • Ce stylo (consonne)
  • Ce téléphone (consonne)
  • Ce héros (h aspiré !)
  • Ce haut-parleur (h aspiré !)

Utilisation de CET

  • Cet ami (voyelle)
  • Cet homme (h muet)
  • Cet ordinateur (voyelle)
  • Cet animal (voyelle)
  • Cet arbre (voyelle)
  • Cet hôtel (h muet)

Comment Reconnaître le H Muet du H Aspiré ?

Astuce Pratique

Test avec l'article défini : Si on peut faire la liaison ou l'élision avec "le" ou "la", c'est un h muet. Sinon, c'est un h aspiré.

Exemples de Test

H muet : l'homme → cet homme (liaison possible)

H muet : l'hôtel → cet hôtel (liaison possible)

H aspiré : le héros → ce héros (pas de liaison)

H aspiré : le haricot → ce haricot (pas de liaison)

🎭 Les Formes Renforcées : -CI et -LÀ

Pour préciser la position dans l'espace ou dans le temps, on peut ajouter les particules -ci (proximité) ou -là (éloignement) au nom précédé de l'adjectif démonstratif.

Utilisation des Particules

-CI
Proximité / Actualité

Ce livre-ci (celui qui est près de moi)

Cette maison-ci (la plus proche)

Ces jours-ci (actuellement)

Cette semaine-ci (la semaine actuelle)

Cet homme-ci (celui qui est ici)

-LÀ
Éloignement / Passé

Ce livre-là (celui qui est loin)

Cette maison-là (la plus éloignée)

Ces jours-là (à cette époque)

Cette année-là (l'année en question)

Cet homme-là (celui qui est là-bas)

Règles d'Emploi

  • -CI indique ce qui est proche dans l'espace ou dans le temps présent
  • -LÀ indique ce qui est éloigné dans l'espace ou dans le temps passé
  • On place le trait d'union entre le nom et la particule : livre-ci, maison-là
  • Au pluriel : ces livres-ci, ces maisons-là
  • En français courant, -là est plus utilisé que -ci

Exemples dans le Contexte

Opposition -CI / -LÀ

Dans l'espace

• Je préfère ce tableau-ci à ce tableau-là.

• Cette voiture-ci est neuve, cette voiture-là est ancienne.

• Regarde cet arbre-là, il est plus grand que cet arbre-ci.

Dans le temps

• Ces jours-ci, il fait très froid. (maintenant)

• Ces jours-là, nous étions en vacances. (à cette époque)

• Cette année-ci sera meilleure. (l'année actuelle)

• Cette année-là, j'ai rencontré mon mari. (l'année en question)

Usage Courant

• Qu'est-ce que c'est que cette histoire-là ? (renforcement)

• Ce garçon-là est très intelligent. (insistance)

• Je n'aime pas ce genre-là. (précision)

Note Importante

En français moderne, -là tend à remplacer -ci dans l'usage courant pour simplement renforcer la démonstration, sans vraiment marquer l'éloignement :

• Ce type-là (= ce type, avec insistance)

• Cette idée-là (= cette idée, avec emphase)

⚠️ Erreurs Courantes à Éviter

Pièges Fréquents

Erreur n°1 : Confondre CE et CET

✗ Ce ami est gentil (INCORRECT)

✓ Cet ami est gentil (CORRECT)

Devant voyelle au masculin → CET

Erreur n°2 : Oublier le H Aspiré

✗ Cet héros est courageux (INCORRECT)

✓ Ce héros est courageux (CORRECT)

H aspiré → CE (pas CET)

Erreur n°3 : Accord Incorrect

✗ Ce maisons sont belles (INCORRECT)

✓ Ces maisons sont belles (CORRECT)

Pluriel → CES (pas CE)

Erreur n°4 : Mauvais Placement du Trait d'Union

✗ Ce-livre là (INCORRECT)

✓ Ce livre-là (CORRECT)

Trait d'union entre le nom et -ci/-là

Erreur n°5 : Confusion avec les Articles

✗ Je veux le livre (quand on montre)

✓ Je veux ce livre (pour montrer)

Pour montrer → adjectif démonstratif

  • Faites attention à l'accord en genre et en nombre

📝 Récapitulatif

Points Clés à Retenir

  • CE : masculin singulier devant consonne ou h aspiré
  • CET : masculin singulier devant voyelle ou h muet
  • CETTE : féminin singulier (tous les cas)
  • CES : pluriel (masculin et féminin)
  • -CI : proximité dans l'espace ou le temps
  • -LÀ : éloignement dans l'espace ou le temps
  • L'adjectif démonstratif accompagne toujours un nom

Schéma Récapitulatif

CE livre / CET ami / CETTE maison / CES enfants

ce livre-CI (proche) ↔ ce livre-LÀ (éloigné)

ces jours-CI (maintenant) ↔ ces jours-LÀ (autrefois)
