🎯 Qu'est-ce qu'un Pronom Démonstratif ?

Le pronom démonstratif est un mot qui remplace un nom en désignant une personne, un animal ou une chose. Contrairement à l'adjectif démonstratif qui accompagne le nom, le pronom démonstratif le remplace complètement.

Différence Fondamentale

  • Adjectif démonstratif : Ce livre est intéressant. (accompagne "livre")
  • Pronom démonstratif : Celui-ci est intéressant. (remplace "ce livre")

Caractéristiques Essentielles

✓ Le pronom démonstratif remplace un groupe nominal

✓ Il s'accorde en genre et en nombre avec le nom qu'il remplace

✓ Il peut être simple ou composé (avec -ci ou -là)

✓ Il existe des formes neutres qui ne représentent pas un nom précis

📋 Les Formes Simples

Les pronoms démonstratifs simples ne peuvent pas être utilisés seuls. Ils doivent être suivis d'un complément ou d'une proposition relative.

Tableau des Formes Simples

Genre et Nombre Forme Utilisation Exemples
Masculin Singulier CELUI Remplace un nom masculin singulier Celui qui travaille réussit
Celui de Pierre
Féminin Singulier CELLE Remplace un nom féminin singulier Celle qui chante est Marie
Celle de ma sœur
Masculin Pluriel CEUX Remplace un nom masculin pluriel Ceux qui viennent
Ceux de mes amis
Féminin Pluriel CELLES Remplace un nom féminin pluriel Celles qui partent
Celles de ma cousine

Règle Importante

Les formes simples CELUI, CELLE, CEUX, CELLES ne s'emploient jamais seules. Elles doivent obligatoirement être suivies de :

  • Une proposition relative : celui qui, celle que, ceux dont, celles auxquelles
  • Un complément introduit par "de" : celui de Pierre, celle de Marie, ceux du professeur
  • Un participe : celui vendu hier, celle achetée en France
✦

Exemples Détaillés

CELUI
Masculin Singulier

• Celui qui parle est mon frère.

• Prends celui que tu préfères.

• Celui de droite est cassé.

• J'aime celui dont tu parles.

• Celui vendu hier était neuf.

CELLE
Féminin Singulier

• Celle qui chante est ma sœur.

• Je préfère celle que tu as achetée.

• Celle de gauche est belle.

• Celle dont je rêve est magnifique.

• Celle vendue en magasin coûte cher.

CEUX
Masculin Pluriel

• Ceux qui travaillent réussissent.

• Choisis ceux que tu veux.

• Ceux de mon père sont neufs.

• Ceux dont tu parles sont partis.

• Ceux exposés ici sont rares.

CELLES
Féminin Pluriel

• Celles qui lisent apprennent.

• Regarde celles que j'ai trouvées.

• Celles de ma mère sont anciennes.

• Celles dont il parle sont parties.

• Celles vendues hier étaient belles.

🎭 Les Formes Composées

Les formes composées sont formées en ajoutant -ci ou -là aux formes simples. Elles peuvent s'utiliser seules, sans complément.

Tableau des Formes Composées

Genre et Nombre Forme avec -CI
(proximité)		 Forme avec -LÀ
(éloignement)
Masculin Singulier celui-ci celui-là
Féminin Singulier celle-ci celle-là
Masculin Pluriel ceux-ci ceux-là
Féminin Pluriel celles-ci celles-là

Distinction -CI / -LÀ

-CI indique la proximité dans l'espace ou dans le temps (ce qui est proche, récent)

-LÀ indique l'éloignement dans l'espace ou dans le temps (ce qui est loin, passé)

• J'aime celui-ci (proche) mais pas celui-là (éloigné)

• Celle-ci est neuve, celle-là est ancienne

Exemples Contextualisés

Dans l'Espace

Opposition Près / Loin

• Regarde ces deux livres : celui-ci est intéressant, celui-là est ennuyeux.

• Entre ces deux robes, je préfère celle-ci à celle-là.

• Ceux-ci sont frais, ceux-là sont périmés.

Dans le Temps

Opposition Récent / Passé

• Entre ces deux périodes, celle-ci est meilleure que celle-là.

• Ceux-ci sont les nouveaux modèles, ceux-là sont les anciens.

Particularité en Français Moderne

Dans la langue courante, -là est plus fréquent que -ci. On utilise souvent -là sans vraiment marquer l'éloignement, simplement pour insister :

• « Je veux celui-là ! » (désignation simple avec emphase)

⚡ Les Formes Neutres

Les pronoms démonstratifs neutres ne remplacent pas un nom précis, mais représentent une idée, une situation, une phrase ou quelque chose d'indéterminé.

Les Trois Formes Neutres

CE
Forme Neutre (devant être)

• Ce sont mes amis.

• C'est une bonne idée.

• Ce sera difficile.

• C'était magnifique.

• Ce doit être lui.

CECI
Forme Neutre (proximité)

• Ceci est important.

• Écoute ceci attentivement.

• Ceci me surprend.

• Retiens ceci : sois patient.

• Ceci dit, nous pouvons continuer.

CELA / ÇA
Forme Neutre (éloignement)

• Cela m'inquiète.

• Ça va bien. (familier)

• Cela ne se fait pas.

• Comment ça va ?

• Cela dit, je suis d'accord.

Différences entre les Formes Neutres

CE : s'utilise uniquement devant le verbe être (ou pouvoir/devoir + être)

CECI : désigne ce qui est proche ou ce qui va être dit

CELA : désigne ce qui est éloigné ou ce qui a été dit

ÇA : forme familière de cela, très utilisée à l'oral

Exemples Contrastifs

Avec CE Avec CECI Avec CELA / ÇA
C'est vrai. Ceci est vrai. Cela est vrai.
Ce sont eux. Retiens ceci. Je sais cela.
C'était bien. Écoute ceci. Ça va ? (familier)
Ce sera long. Ceci m'intéresse. Ça m'ennuie.

Usage de CECI et CELA

CECI annonce ce qui va suivre :

• Retenez bien ceci : le travail paie toujours.

CELA reprend ce qui précède :

• Il pleut depuis une semaine. Cela devient inquiétant.

⚠️ Erreurs Courantes

Pièges à Éviter

Erreur n°1 : Forme Simple Seule

✗ Je veux celui. (INCORRECT)

✓ Je veux celui-ci. (CORRECT)

✓ Je veux celui qui est rouge. (CORRECT)

→ Les formes simples exigent un complément

Erreur n°2 : Mauvais Accord

✗ Les livres ? Celui-ci sont neufs. (INCORRECT)

✓ Les livres ? Ceux-ci sont neufs. (CORRECT)

→ Accord obligatoire en genre et nombre

Erreur n°3 : Confusion CE / CELA

✗ Cela est mon frère. (INCORRECT)

✓ C'est mon frère. (CORRECT)

✓ Cela m'inquiète. (CORRECT - pas le verbe être)

→ CE uniquement devant être

Erreur n°4 : Oubli du Trait d'Union

✗ Celui ci est mieux. (INCORRECT)

✓ Celui-ci est mieux. (CORRECT)

→ Toujours un trait d'union avec -ci et -là

✍️ Exercices Pratiques

Exercice 1 : Complétez avec le pronom démonstratif correct

1. J'ai deux stylos : _______ est bleu, _______ est rouge. (-ci / -là)

2. Voici deux livres. Je préfère _______ qui parle d'histoire. (celui/celle)

3. Ces voitures sont chères. _______ de mon père l'est aussi. (celui/celle)

4. _______ qui travaille réussit. (celui/ceux)

5. _______ est important : sois patient. (ce/ceci/cela)

6. _______ mes amis. (c'est/ce sont)

Exercice 2 : Transformez avec un pronom démonstratif

1. Ce livre est intéressant. → _______ est intéressant.

2. Cette maison me plaît. → _______ me plaît.

3. Ces enfants jouent. → _______ jouent.

4. J'aime les films qui font réfléchir. → J'aime _______ qui font réfléchir.

Conseils pour Progresser

  • Distinguez toujours les formes simples (besoin d'un complément) des formes composées (autonomes)
  • Faites attention à l'accord en genre et en nombre
  • N'oubliez pas le trait d'union avec -ci et -là
  • Utilisez CE uniquement devant le verbe être
  • Pratiquez avec des exemples contrastifs (celui-ci vs celui-là)

📝 Récapitulatif Complet

Synthèse des Formes

  • Formes simples : celui, celle, ceux, celles (+ complément obligatoire)
  • Formes composées : celui-ci/là, celle-ci/là, ceux-ci/là, celles-ci/là (autonomes)
  • Formes neutres : ce (devant être), ceci (proximité), cela/ça (éloignement)
  • Accord : toujours en genre et nombre avec le nom remplacé
  • Trait d'union : obligatoire avec -ci et -là
