Le Pronom Personnel Réfléchi

Comprendre et maîtriser les verbes pronominaux

Les pronoms personnels réfléchis sont des pronoms spéciaux utilisés avec les verbes pronominaux. Ils indiquent que l'action du verbe "revient" sur le sujet : la personne fait l'action sur elle-même.

Ces pronoms sont essentiels en français car de nombreux verbes sont pronominaux. Leur maîtrise est indispensable pour s'exprimer correctement au quotidien.

📚 Définition : Le pronom réfléchi

Un pronom réfléchi est un pronom personnel qui renvoie au sujet du verbe. Il accompagne les verbes pronominaux et se place toujours avant le verbe (sauf à l'impératif affirmatif).

📋Les formes des pronoms réfléchis

🎯 Tableau complet des pronoms réfléchis
ME
1ère personne
singulier
Je me lave.
TE
2ème personne
singulier
Tu te laves.
SE
3ème personne
singulier
Il/Elle se lave.
NOUS
1ère personne
pluriel
Nous nous lavons.
VOUS
2ème personne
pluriel
Vous vous lavez.
SE
3ème personne
pluriel
Ils/Elles se lavent.
💡 Observation importante : Les pronoms réfléchis sont identiques aux pronoms COD/COI pour les 1ère et 2ème personnes (me, te, nous, vous). Seule la 3ème personne a une forme spécifique : SE (au lieu de le/la/les ou lui/leur).

📐 Élision

Les pronoms ME, TE, SE deviennent M', T', S' devant une voyelle ou un h muet.

  • Je m'appelle Marie. (s'appeler)
  • Tu t'habilles vite. (s'habiller)
  • Il s'amuse bien. (s'amuser)
  • Elle s'endort tard. (s'endormir)

🔄Les verbes pronominaux

📖 Définition et caractéristiques

Qu'est-ce qu'un verbe pronominal ?

Un verbe pronominal est un verbe qui se conjugue avec un pronom réfléchi. Ce pronom renvoie au sujet et indique que l'action "revient" sur le sujet lui-même.

Structure d'un verbe pronominal

SUJET
+
PRONOM RÉFLÉCHI
+
VERBE
Exemple : Je me lave / Tu te promènes / Il se réveille

📋 Conjugaison complète : SE LAVER (présent)

Je me lave
Tu te laves
Il/Elle se lave
Nous nous lavons
Vous vous lavez
Ils/Elles se lavent

🎭Les types de verbes pronominaux

Il existe plusieurs types de verbes pronominaux selon la relation entre le sujet et l'action. Chaque type a ses propres caractéristiques et usages.

1️⃣ Verbes pronominaux RÉFLÉCHIS

Le sujet fait l'action sur lui-même. On peut ajouter "moi-même", "toi-même", etc.

Se laver : Je me lave. (= Je lave moi-même)
→ Je fais l'action de laver sur moi
Se coiffer : Elle se coiffe devant le miroir.
→ Elle coiffe ses propres cheveux
Se raser : Il se rase tous les matins.
→ Il rase sa propre barbe
Se regarder : Tu te regardes dans la glace.
→ Tu regardes toi-même
💡 Liste de verbes réfléchis courants :
  • se laver (laver soi-même)
  • se coiffer (coiffer soi-même)
  • s'habiller (habiller soi-même)
  • se maquiller
  • se raser
  • se brosser (les dents)
  • se parfumer
  • se peigner

2️⃣ Verbes pronominaux RÉCIPROQUES

Les sujets font l'action l'un sur l'autre ou les uns sur les autres. Toujours au pluriel !

Se parler : Paul et Marie se parlent souvent.
→ Paul parle à Marie ET Marie parle à Paul
Se téléphoner : Nous nous téléphonons tous les jours.
→ Je téléphone à toi ET tu téléphones à moi
S'embrasser : Ils s'embrassent tendrement.
→ Il embrasse elle ET elle embrasse lui
Se rencontrer : Nous nous sommes rencontrés en 2020.
→ Action mutuelle de rencontre
Se disputer : Les enfants se disputent pour le jouet.
→ Ils disputent l'un avec l'autre
💡 Liste de verbes réciproques courants :
  • se parler
  • se téléphoner
  • s'écrire
  • se voir
  • se rencontrer
  • s'embrasser
  • se saluer
  • se disputer
  • s'aimer
  • se détester
  • s'entraider
  • se comprendre

3️⃣ Verbes ESSENTIELLEMENT pronominaux

Ces verbes existent uniquement à la forme pronominale. On ne peut pas les utiliser sans le pronom réfléchi.

S'absenter : Je m'absente quelques minutes.
→ ❌ "absenter" n'existe pas seul
S'évanouir : Elle s'est évanouie à cause de la chaleur.
→ ❌ "évanouir" n'existe pas seul
Se souvenir (de) : Tu te souviens de moi ?
→ ❌ "souvenir" seul n'est qu'un nom
S'enfuir : Le voleur s'est enfui rapidement.
→ ❌ "enfuir" n'existe pas seul
Se méfier (de) : Il faut se méfier des arnaques.
→ ❌ "méfier" n'existe pas seul
💡 Liste de verbes essentiellement pronominaux :
  • s'absenter
  • s'évanouir
  • se souvenir (de)
  • s'enfuir
  • se méfier (de)
  • s'en aller
  • se repentir (de)
  • s'écrier
  • s'emparer (de)
  • se désister
  • s'évader
  • s'acharner (à)

4️⃣ Verbes pronominaux à SENS PASSIF

Le pronom SE a un sens passif. Le sujet subit l'action plutôt que de la faire.

Se vendre : Ce livre se vend bien.
→ = Ce livre est vendu (par quelqu'un)
Se manger : La pizza se mange chaude.
→ = La pizza est mangée chaude
Se dire : Cela ne se dit pas !
→ = Cela n'est pas dit / On ne dit pas cela
Se voir : L'église se voit de loin.
→ = L'église est vue / peut être vue de loin
Se comprendre : Son comportement se comprend facilement.
→ = Son comportement est compris / peut être compris

5️⃣ Verbes à CHANGEMENT DE SENS

Certains verbes changent complètement de sens selon qu'ils sont pronominaux ou non.

🔍 Exemples de changements de sens

❌ Sans pronom
Apercevoir :
J'aperçois la tour Eiffel.
= voir, distinguer
✅ Avec pronom (s'apercevoir)
S'apercevoir :
Je m'aperçois de mon erreur.
= se rendre compte, réaliser
❌ Attendre
J'attends le bus.
= patienter pour quelque chose
✅ S'attendre à
Je m'attends à réussir.
= prévoir, anticiper
❌ Ennuyer
Ce film m'ennuie.
= rendre quelqu'un qui s'ennuie
✅ S'ennuyer
Je m'ennuie en cours.
= ressentir de l'ennui
❌ Demander
Je demande l'addition.
= solliciter quelque chose
✅ Se demander
Je me demande pourquoi.
= se poser une question

📍Position du pronom réfléchi

🎯 Règles de placement

La position du pronom réfléchi dépend du temps et du mode du verbe. Voici toutes les situations possibles.

1️⃣ Temps simples (présent, imparfait, futur...)

Règle : Pronom AVANT le verbe

Présent : Je me lève tôt.
Imparfait : Tu te promenais dans le parc.
Futur : Elle se reposera demain.
2️⃣ Temps composés (passé composé, plus-que-parfait...)

Règle : Pronom AVANT l'auxiliaire

Passé composé : Je me suis levé(e) tôt.
Plus-que-parfait : Tu t'étais promené(e) dans le parc.
Futur antérieur : Elle se sera reposée avant ce soir.
3️⃣ Avec un infinitif

Règle : Pronom AVANT l'infinitif

Exemple 1 : Je vais me promener.
Exemple 2 : Tu dois te reposer.
Exemple 3 : Il veut se lever tôt.
Exemple 4 : Nous aimons nous promener le dimanche.
4️⃣ À la forme négative

Règle : NE + pronom + verbe + PAS

Présent : Je ne me lève pas tôt.
Passé composé : Tu ne t'es pas promené(e).
Avec infinitif : Il ne veut pas se lever.
5️⃣ À l'impératif AFFIRMATIF

Règle : Pronom APRÈS le verbe (avec trait d'union)

⚠️ Attention : ME et TE deviennent MOI et TOI après le verbe !
2ème pers. sing. : Lève-toi ! (pas "lève-te")
1ère pers. plur. : Levons-nous !
2ème pers. plur. : Levez-vous !
Autres exemples :
Dépêche-toi !
Repose-toi bien !
Amusez-vous bien !
6️⃣ À l'impératif NÉGATIF

Règle : Pronom AVANT le verbe (comme d'habitude)

2ème pers. sing. : Ne te lève pas ! (pas "ne lève-toi pas")
1ère pers. plur. : Ne nous levons pas !
2ème pers. plur. : Ne vous levez pas !
Autres exemples :
Ne te dépêche pas !
Ne vous inquiétez pas !

🔍 Comparaison impératif affirmatif vs négatif

✅ AFFIRMATIF
Lève-toi !
Repose-toi !
Dépêche-toi !
Amusez-vous !
❌ NÉGATIF
Ne te lève pas !
Ne te repose pas !
Ne te dépêche pas !
Ne vous amusez pas !

📝Accord du participe passé avec les verbes pronominaux

⚖️ Règles d'accord
⚠️ Règle générale : Les verbes pronominaux se conjuguent TOUJOURS avec l'auxiliaire ÊTRE aux temps composés, mais l'accord du participe passé suit des règles spéciales.

📐 Règle 1 : Verbes essentiellement pronominaux

Le participe passé s'accorde TOUJOURS avec le sujet.

Elle s'est évanouie. (s'évanouir - essentiellement pronominal)
Ils se sont absentés. (s'absenter)
Elles se sont enfuies. (s'enfuir)

📐 Règle 2 : Verbes pronominaux réfléchis et réciproques

Le participe passé s'accorde avec le COD s'il est placé avant le verbe.

✅ Accord (COD = pronom réfléchi avant le verbe)
Elle s'est lavée.
→ Elle a lavé qui ? se (= elle) → accord
Ils se sont regardés dans le miroir.
→ Ils ont regardé qui ? se (= eux) → accord
❌ Pas d'accord (COD après le verbe ou COI)
Elle s'est lavé les mains.
→ Elle a lavé quoi ? les mains (après) → pas d'accord
Ils se sont parlé.
→ Ils ont parlé à qui ? à eux (COI) → pas d'accord
Elles se sont téléphoné.
→ Elles ont téléphoné à qui ? à elles (COI) → pas d'accord

🔍 Exemples détaillés d'accord

Phrase Analyse Accord ?
Elle s'est levée tôt. Elle a levé se (= elle) → COD avant ✅ OUI
Ils se sont rencontrés. Ils ont rencontré se (= eux) → COD avant ✅ OUI
Elle s'est lavé les cheveux. Elle a lavé les cheveux → COD après ❌ NON
Ils se sont écrit des lettres. Ils ont écrit à eux → COI (pas COD) ❌ NON
Elles se sont parlé. Elles ont parlé à elles → COI ❌ NON
Elle s'est coupée avec un couteau. Elle a coupé se (= elle) → COD avant ✅ OUI
Elle s'est coupé le doigt. Elle a coupé le doigt → COD après ❌ NON
💡 Astuce pour savoir :
  1. Remplacez l'auxiliaire ÊTRE par AVOIR
  2. Posez la question : verbe + qui/quoi ?
  3. Si la réponse est le pronom réfléchi (= le sujet) → accord
  4. Si la réponse est un autre mot qui vient après → pas d'accord
  5. Si c'est un COI (à + pronom) → jamais d'accord

📝Récapitulatif

✅ Points essentiels à retenir

  • Les pronoms réfléchis sont : me, te, se, nous, vous, se
  • Ils s'utilisent avec les verbes pronominaux
  • Position normale : avant le verbe
  • Exception : après le verbe à l'impératif affirmatif (+ trait d'union)
  • ME et TE deviennent MOI et TOI à l'impératif affirmatif
  • Temps composés : auxiliaire ÊTRE obligatoire
  • Accord du participe : suit des règles spécifiques selon le type
💡 Pour progresser :
  • Apprenez les verbes pronominaux courants par cœur
  • Pratiquez la conjugaison avec les pronoms réfléchis
  • Faites attention à la position à l'impératif
  • Révisez les règles d'accord du participe passé
  • Utilisez ces verbes dans vos conversations quotidiennes
