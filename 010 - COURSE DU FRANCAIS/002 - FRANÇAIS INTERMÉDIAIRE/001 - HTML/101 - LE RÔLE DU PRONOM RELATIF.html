Les Pronoms et Adjectifs Relatifs

Généralités · Le Rôle du Pronom Relatif

Qu'est-ce qu'un pronom relatif ?

Le pronom relatif est un mot qui établit un lien entre deux propositions en remplaçant un nom ou un pronom déjà mentionné (appelé antécédent). Il permet d'éviter les répétitions et de créer des phrases plus fluides et élégantes. Le pronom relatif introduit une proposition subordonnée relative qui complète ou précise le sens de l'antécédent.

🎯 Fonction Essentielle

Le pronom relatif a un double rôle : il remplace un nom (comme tout pronom) et il relie deux propositions (comme une conjonction). C'est cette double fonction qui fait toute sa richesse dans la langue française.

Les pronoms relatifs principaux en français sont : qui, que, quoi, dont, où (formes simples) et lequel, laquelle, lesquels, lesquelles, duquel, auquel... (formes composées). Chacun a ses fonctions grammaticales spécifiques et son usage approprié.

Le Rôle du Pronom Relatif

Le pronom relatif remplit trois rôles fondamentaux dans la phrase :

1. Représentation : Il représente un nom ou un pronom déjà exprimé, appelé antécédent, pour éviter sa répétition.

2. Subordination : Il introduit une proposition subordonnée relative qui dépend de la proposition principale.

3. Fonction grammaticale : Il a une fonction grammaticale propre dans la subordonnée relative (sujet, COD, COI, complément du nom, etc.).

L'Antécédent

L'antécédent est le mot (nom, pronom, ou proposition) que le pronom relatif représente et auquel il se rapporte. Il se trouve généralement juste avant le pronom relatif.

Accord : Le pronom relatif prend le genre et le nombre de son antécédent, ce qui influence parfois l'accord du verbe ou des participes dans la relative.

Position : L'antécédent précède presque toujours le pronom relatif, sauf dans certaines constructions littéraires ou avec les relatifs sans antécédent.

Différence : Pronom vs Adjectif

Il est important de distinguer le pronom relatif de l'adjectif relatif :

Pronom relatif : Remplace un nom et introduit une proposition. Il a une fonction dans la relative. Exemple : "le livre que je lis"

Adjectif relatif : Précède un nom et l'accompagne (rare en français moderne). On utilise plutôt "quel(le)(s)" dans les interrogatives. L'usage classique du relatif-adjectif se trouve surtout dans des expressions figées ou en littérature : "auquel cas", "lequel livre" (vieilli).

Exemples Détaillés

La femme qui parle est ma professeure.

→ Antécédent : "la femme" (féminin singulier)
→ Pronom relatif : "qui" (sujet du verbe "parle")
→ Fonction : Le pronom "qui" est sujet dans la proposition relative

Le livre que tu lis est passionnant.

→ Antécédent : "le livre" (masculin singulier)
→ Pronom relatif : "que" (COD du verbe "lis")
→ Fonction : Le pronom "que" est complément d'objet direct de "lis"

L'auteur dont je parle est célèbre.

→ Antécédent : "l'auteur" (masculin singulier)
→ Pronom relatif : "dont" (complément de "parle")
→ Fonction : "Dont" remplace "de l'auteur" (je parle de l'auteur)

La ville où je suis né est magnifique.

→ Antécédent : "la ville" (féminin singulier)
→ Pronom relatif : "où" (complément circonstanciel de lieu)
→ Fonction : "Où" indique le lieu (je suis né dans cette ville)

Les problèmes auxquels nous pensons sont importants.

→ Antécédent : "les problèmes" (masculin pluriel)
→ Pronom relatif : "auxquels" (à + lesquels, COI de "pensons")
→ Fonction : Complément du verbe "penser à" (nous pensons à ces problèmes)

La raison pour laquelle je t'appelle est urgente.

→ Antécédent : "la raison" (féminin singulier)
→ Pronom relatif composé : "pour laquelle"
→ Fonction : Complément circonstanciel de cause

Les amis avec lesquels je voyage sont sympathiques.

→ Antécédent : "les amis" (masculin pluriel)
→ Pronom relatif composé : "avec lesquels"
→ Fonction : Complément circonstanciel d'accompagnement

Tout ce qui brille n'est pas or.

→ Antécédent : "ce" (pronom démonstratif neutre)
→ Pronom relatif : "qui" (sujet de "brille")
→ Remarque : "Ce qui" est utilisé sans antécédent nominal précis

Points Importants à Retenir

  • Le pronom relatif évite les répétitions : Il permet de relier deux phrases en une seule, rendant le discours plus fluide et élégant.
  • Il a toujours un antécédent (sauf dans certaines expressions comme "qui que", "quoi que") : L'antécédent est le mot que le pronom relatif représente.
  • Le choix du pronom dépend de sa fonction : sujet (qui), COD (que), complément introduit par "de" (dont), lieu/temps (où), après préposition (lequel, etc.).
  • "Qui" ne s'élide jamais : On écrit toujours "qui", même devant une voyelle. En revanche, "que" devient "qu'" devant une voyelle.
  • Les formes composées (lequel, laquelle...) s'accordent en genre et en nombre avec leur antécédent et peuvent se contracter avec "à" et "de".
  • L'accord du participe passé : Avec "que" COD placé avant le verbe, le participe passé s'accorde avec l'antécédent. Ex: "Les fleurs que j'ai achetées".
  • La proposition relative peut être déterminative (essentielle au sens) ou explicative (apporte une information supplémentaire, entre virgules).

À Noter : Différence avec l'Adjectif Relatif

En français moderne, l'adjectif relatif est rare et souvent remplacé par des tournures avec "quel(le)(s)" dans les interrogatives indirectes. Les formes comme "lequel" peuvent fonctionner comme adjectifs dans des expressions figées anciennes ("lequel homme", "laquelle femme"), mais cet usage est devenu archaïque. On trouve encore "auquel cas", "moyennant quoi" dans la langue soutenue. En pratique, "lequel" est aujourd'hui principalement utilisé comme pronom relatif après une préposition.

Exemples Complémentaires de Transformation

❌ J'ai rencontré un homme. Cet homme était très gentil.

✅ J'ai rencontré un homme qui était très gentil.
→ Le pronom "qui" remplace "cet homme" et évite la répétition.

❌ J'ai lu un roman. Tu m'as recommandé ce roman.

✅ J'ai lu le roman que tu m'as recommandé.
→ Le pronom "que" remplace "ce roman" qui est COD de "recommander".

❌ Voici l'artiste. Je t'ai parlé de cet artiste.

✅ Voici l'artiste dont je t'ai parlé.
→ "Dont" remplace "de cet artiste" (parler de quelqu'un).

❌ C'est la ville. Je suis né dans cette ville.

✅ C'est la ville où je suis né.
→ "Où" remplace "dans cette ville" et indique le lieu.

❌ Voici les documents. J'ai besoin de ces documents.

✅ Voici les documents dont j'ai besoin.
OU : Voici les documents desquels j'ai besoin. (plus soutenu)
→ "Dont" ou "desquels" remplace "de ces documents" (avoir besoin de).

❌ J'ai choisi une méthode. Je réussis grâce à cette méthode.

✅ J'ai choisi une méthode grâce à laquelle je réussis.
→ "Grâce à laquelle" remplace "grâce à cette méthode".

❌ Ce sont des collègues. Je travaille avec ces collègues.

✅ Ce sont des collègues avec lesquels (ou avec qui) je travaille.
→ "Avec lesquels" ou "avec qui" remplace "avec ces collègues".

❌ Le moment est arrivé. Je redoutais ce moment.

✅ Le moment que je redoutais est arrivé.
→ "Que" est COD de "redouter" et remplace "ce moment".

Exemples avec les Formes Composées

La table sur laquelle je travaille est confortable.

→ Préposition "sur" + pronom relatif "laquelle" (féminin singulier)

Les principes auxquels je crois sont importants.

→ "Auxquels" = à + lesquels (masculin pluriel) - verbe "croire à"

La fenêtre par laquelle je regarde donne sur le jardin.

→ Préposition "par" + pronom relatif "laquelle" (féminin singulier)

Les associations pour lesquelles je travaille sont humanitaires.

→ Préposition "pour" + pronom relatif "lesquelles" (féminin pluriel)

Le pont sous lequel passe la rivière est ancien.

→ Préposition "sous" + pronom relatif "lequel" (masculin singulier)

Les circonstances dans lesquelles nous nous sommes rencontrés étaient particulières.

→ Préposition "dans" + pronom relatif "lesquelles" (féminin pluriel)

Le parc à côté duquel j'habite est magnifique.

→ "Duquel" = de + lequel (masculin singulier) - locution prépositive "à côté de"

Les raisons pour lesquelles je refuse sont claires.

→ Préposition "pour" + pronom relatif "lesquelles" (féminin pluriel)

💡 Astuce Pratique

Pour choisir le bon pronom relatif, posez-vous ces questions :

1. Quelle est la fonction grammaticale dans la relative ?
2. Y a-t-il une préposition ? Si oui, laquelle ?
3. Quel est le genre et le nombre de l'antécédent ?

Ces trois questions vous guideront vers le bon choix : qui (sujet), que (COD), dont (complément avec "de"), où (lieu/temps), ou les formes composées avec lequel après d'autres prépositions.
