Les Pronoms Relatifs

Formes et Fonctions Grammaticales

Vue d'Ensemble des Formes

Les pronoms relatifs en français se divisent en deux grandes catégories : les formes simples (qui, que, quoi, dont, où) et les formes composées (lequel, laquelle, lesquels, lesquelles et leurs variantes contractées). Chaque forme a des fonctions grammaticales spécifiques et des règles d'emploi précises qui déterminent son usage dans la phrase.

Le choix du pronom relatif approprié dépend de trois facteurs essentiels : la fonction grammaticale du pronom dans la proposition relative, la présence ou l'absence d'une préposition, et parfois la nature de l'antécédent (personne, chose, ou proposition).

📝

Formes Simples

Les pronoms relatifs simples sont invariables (sauf "où") et s'utilisent sans préposition ou avec des prépositions spécifiques. Ils représentent la majorité des cas d'usage : qui (sujet), que (COD), dont (complément avec "de"), où (lieu/temps), et quoi (chose, après préposition).

🔄

Formes Composées

Les pronoms relatifs composés s'accordent en genre et en nombre avec leur antécédent : lequel, laquelle, lesquels, lesquelles. Ils s'utilisent principalement après des prépositions (sauf "de") et peuvent se contracter avec "à" et "de" pour former auquel, duquel, etc.

⚙️

Fonctions Grammaticales

Chaque pronom relatif remplit une fonction grammaticale spécifique dans la proposition relative : sujet du verbe, complément d'objet direct, complément d'objet indirect, complément circonstanciel, ou complément du nom. La fonction détermine le choix du pronom approprié.

🎯

Cas Particuliers

Certaines situations requièrent une attention particulière : les relatifs sans antécédent (qui que, quoi que), les constructions avec "ce" (ce qui, ce que, ce dont), l'élision de "que", les accords du participe passé, et le choix entre formes simples et composées après préposition.

Les Formes Simples : Tableau Détaillé

Pronom Fonction(s) Usage Exemple
QUI Sujet Personnes ou choses, jamais élidé L'homme qui parle est mon père
QUE / QU' COD S'élide devant voyelle ou h muet Le livre que je lis / qu'il aime
QUOI Après préposition Uniquement pour les choses Ce à quoi je pense
DONT Compl. avec "de" Remplace "de + nom", jamais après préposition Le livre dont je parle
OÙ Lieu ou Temps Circonstanciel de lieu ou de temps La ville où j'habite / Le jour où je suis né

Exemples Détaillés : Formes Simples

La femme qui chante a une voix magnifique.

→ Pronom : "qui" (forme simple invariable)
→ Fonction : Sujet du verbe "chante" dans la proposition relative
→ Antécédent : "la femme" (féminin singulier)
→ Remarque : "Qui" ne s'élide jamais, même devant une voyelle

Les films que nous avons regardés étaient captivants.

→ Pronom : "que" (forme simple invariable)
→ Fonction : COD du verbe "regarder" dans la proposition relative
→ Antécédent : "les films" (masculin pluriel)
→ Accord : Le participe passé "regardés" s'accorde avec "que" (= les films) placé avant

Voici ce à quoi je faisais allusion.

→ Pronom : "à quoi" (préposition + forme simple)
→ Fonction : Complément du verbe "faire allusion à"
→ Antécédent : "ce" (pronom démonstratif neutre)
→ Remarque : "Quoi" s'utilise uniquement pour les choses, après préposition

L'auteur dont j'ai lu tous les romans vient de publier un nouveau livre.

→ Pronom : "dont" (forme simple invariable)
→ Fonction : Complément du nom "romans" (les romans de l'auteur)
→ Antécédent : "l'auteur" (masculin singulier)
→ Remarque : "Dont" remplace toujours un complément introduit par "de"

La maison où je suis né a été démolie.

→ Pronom : "où" (forme simple invariable)
→ Fonction : Complément circonstanciel de lieu
→ Antécédent : "la maison" (féminin singulier)
→ Remarque : "Où" indique le lieu (dans cette maison)

Je me souviens du jour où nous nous sommes rencontrés.

→ Pronom : "où" (forme simple invariable)
→ Fonction : Complément circonstanciel de temps
→ Antécédent : "le jour" (masculin singulier)
→ Remarque : "Où" peut aussi exprimer le temps avec des antécédents temporels

La raison dont il parle n'est pas valable.

→ Pronom : "dont" (forme simple invariable)
→ Fonction : COI du verbe "parler de"
→ Antécédent : "la raison" (féminin singulier)
→ Construction : parler de quelque chose → dont (il parle de cette raison)

Tout ce qui brille n'est pas or.

→ Pronom : "qui" (forme simple invariable)
→ Fonction : Sujet du verbe "briller"
→ Antécédent : "ce" (pronom démonstratif neutre)
→ Construction : "Ce qui" = la chose qui / ce que (neutre)

Exemples Détaillés : Formes Composées

La table sur laquelle je travaille est en bois massif.

→ Pronom : "sur laquelle" (préposition + forme composée)
→ Fonction : Complément circonstanciel de lieu
→ Antécédent : "la table" (féminin singulier)
→ Accord : "laquelle" s'accorde en genre (f.) et nombre (s.) avec "la table"

Les principes auxquels je crois sont fondamentaux.

→ Pronom : "auxquels" = à + lesquels (contraction)
→ Fonction : COI du verbe "croire à"
→ Antécédent : "les principes" (masculin pluriel)
→ Construction : croire à quelque chose → auxquels (je crois à ces principes)

La fenêtre par laquelle entre la lumière donne sur le jardin.

→ Pronom : "par laquelle" (préposition + forme composée)
→ Fonction : Complément circonstanciel de moyen/lieu
→ Antécédent : "la fenêtre" (féminin singulier)
→ Remarque : Indique le passage (la lumière entre par cette fenêtre)

Les associations pour lesquelles elle travaille sont humanitaires.

→ Pronom : "pour lesquelles" (préposition + forme composée)
→ Fonction : Complément circonstanciel de but
→ Antécédent : "les associations" (féminin pluriel)
→ Accord : "lesquelles" s'accorde avec "les associations" (f. pl.)

Le pont sous lequel passe la rivière date du XIXe siècle.

→ Pronom : "sous lequel" (préposition + forme composée)
→ Fonction : Complément circonstanciel de lieu
→ Antécédent : "le pont" (masculin singulier)
→ Remarque : Indique la position (la rivière passe sous ce pont)

Les circonstances dans lesquelles nous nous sommes rencontrés étaient particulières.

→ Pronom : "dans lesquelles" (préposition + forme composée)
→ Fonction : Complément circonstanciel de manière
→ Antécédent : "les circonstances" (féminin pluriel)
→ Accord : "lesquelles" s'accorde avec "les circonstances" (f. pl.)

Le parc à côté duquel j'habite est magnifique.

→ Pronom : "duquel" = de + lequel (contraction)
→ Fonction : Complément de la locution prépositive "à côté de"
→ Antécédent : "le parc" (masculin singulier)
→ Construction : à côté de + nom → à côté duquel

Les montagnes au pied desquelles s'étend la vallée sont enneigées.

→ Pronom : "desquelles" = de + lesquelles (contraction)
→ Fonction : Complément de la locution prépositive "au pied de"
→ Antécédent : "les montagnes" (féminin pluriel)
→ Construction : au pied de + nom → au pied desquelles

Attention : Choix entre "dont" et "duquel"

Règle importante : Après une locution prépositive contenant "de" (à côté de, près de, loin de, au milieu de, etc.), on utilise "duquel/de laquelle/desquels/desquelles" et NON "dont".

✅ La maison à côté de laquelle j'habite...
❌ La maison à côté dont j'habite... (incorrect)

✅ Le parc au milieu duquel se trouve une fontaine...
❌ Le parc au milieu dont se trouve une fontaine... (incorrect)

Pourquoi ? "Dont" ne peut jamais suivre une préposition. Quand "de" fait partie d'une locution prépositive, on doit utiliser les formes composées avec "de" : duquel, de laquelle, desquels, desquelles.

Formes Simples vs Composées

  • Après "à" et "de" : On peut utiliser "qui" pour les personnes OU les formes composées pour plus de clarté
    L'ami à qui / auquel je pense
  • Après d'autres prépositions : Obligatoire d'utiliser les formes composées
    Le stylo avec lequel j'écris (pas "avec qui")
  • Pour les choses : Toujours les formes composées après préposition
    La chaise sur laquelle je suis assis
  • Avec "dont" : On utilise "dont" directement, jamais "de qui" ou "duquel" sauf après locution prépositive
    L'auteur dont je parle

Règles d'Accord et de Contraction

  • Accord : Les formes composées s'accordent toujours en genre et nombre avec leur antécédent
    lequel (m.s.), laquelle (f.s.), lesquels (m.pl.), lesquelles (f.pl.)
  • Contraction avec "à" : Au masculin seulement
    à + lequel = auquel / à + lesquels = auxquels
    Mais : à + laquelle / à + lesquelles (pas de contraction)
  • Contraction avec "de" : Au masculin seulement
    de + lequel = duquel / de + lesquels = desquels
    Mais : de + laquelle / de + lesquelles (pas de contraction)
  • Autres prépositions : Aucune contraction possible
    pour lequel, avec laquelle, sans lesquels, etc.

Astuce pour Choisir le Bon Pronom

Méthode en 4 étapes :

1. Identifiez l'antécédent : Quel mot le pronom remplace-t-il ?
2. Déterminez la fonction : Quelle est la fonction grammaticale dans la relative ?
3. Vérifiez la préposition : Y a-t-il une préposition ? Laquelle ?
4. Choisissez le pronom :
• Sujet → qui
• COD → que
• Avec "de" (complément) → dont
• Lieu/temps → où
• Autre préposition → formes composées (lequel, etc.)
• Locution avec "de" → duquel, de laquelle, etc.

Exemples Complexes et Cas Spéciaux

C'est la seule solution à laquelle je n'avais pas pensé.

→ Verbe "penser à" → COI avec "à"
→ Antécédent : "la solution" (féminin singulier) → "à laquelle"
→ Pas de contraction au féminin : "à laquelle" (et non "alaquelle")

Les documents dont vous avez besoin sont dans le tiroir.

→ Verbe "avoir besoin de" → complément avec "de"
→ On utilise "dont" (vous avez besoin de ces documents)
→ Alternative possible mais plus lourde : "desquels vous avez besoin"

Ce à quoi tu fais référence n'est pas clair.

→ Antécédent neutre "ce" → on utilise "quoi" après préposition
→ Verbe "faire référence à" → préposition "à"
→ Construction : ce + à + quoi (chose abstraite)

L'immeuble en face duquel se trouve le parc vient d'être rénové.

→ Locution prépositive "en face de" → on utilise "duquel"
→ Impossible d'utiliser "dont" après une locution prépositive
→ Antécédent : "l'immeuble" (masculin singulier) → "duquel"

Les collègues avec qui (ou avec lesquels) je travaille sont compétents.

→ Antécédent = personnes → on peut utiliser "qui" OU "lesquels"
→ "Avec qui" est plus courant et naturel
→ "Avec lesquels" est plus soutenu et plus précis

C'est un écrivain dont l'œuvre est reconnue mondialement.

→ "Dont" complément du nom "œuvre"
→ Construction : l'œuvre de cet écrivain → dont l'œuvre
→ "Dont" introduit un complément du nom (possesseur)

Voici ce dont je voulais te parler.

→ Construction avec pronom démonstratif neutre "ce"
→ Verbe "parler de" → "dont"
→ "Ce dont" = la chose dont (objet abstrait ou non défini)

La manière dont il s'exprime est élégante.

→ "Dont" peut aussi remplacer "de la façon que"
→ Équivalent à : "La manière de laquelle il s'exprime" (rare)
→ "Dont" est ici préférable et plus naturel

Points Fondamentaux à Maîtriser

  • QUI est toujours sujet et ne s'élide jamais, même devant une voyelle. Le verbe de la relative s'accorde avec l'antécédent de "qui".
  • QUE est toujours COD et s'élide en "qu'" devant voyelle ou h muet. Le participe passé s'accorde avec l'antécédent quand "que" est placé avant le verbe.
  • DONT remplace toujours un complément avec "de" et ne peut jamais être précédé d'une préposition. Il s'utilise pour : COI (parler de), complément du nom (le livre de...), complément de l'adjectif (fier de), agent du passif (entouré de).
  • OÙ s'utilise pour les compléments circonstanciels de lieu et de temps. Il remplace "dans lequel, sur lequel, etc." pour les lieux et "pendant lequel, durant lequel" pour le temps.
  • LEQUEL et ses variantes s'accordent en genre et en nombre avec leur antécédent. Ils s'utilisent après toutes les prépositions (sauf "de" seul), et se contractent avec "à" et "de" au masculin uniquement.
  • Pour les personnes après "à" et "de" : on peut utiliser "qui" (courant) ou les formes composées (soutenu). Pour les choses, on utilise obligatoirement les formes composées.
  • Après une locution prépositive contenant "de" (à côté de, près de, au milieu de, loin de, etc.), on utilise "duquel/de laquelle/desquels/desquelles" et jamais "dont".
  • CE QUI, CE QUE, CE DONT, CE À QUOI : Ces constructions avec le pronom démonstratif neutre "ce" permettent de créer des relatives sans antécédent nominal précis. Elles représentent une chose abstraite ou une idée.

Récapitulatif : Comment Choisir ?

🎯 Pour bien choisir votre pronom relatif, suivez ce guide :

Sans préposition :
• Fonction sujet → QUI
• Fonction COD → QUE
• Complément avec "de" → DONT
• Lieu ou temps → OÙ

Avec préposition :
• Préposition "de" seule → DONT
• Locution avec "de" → DUQUEL, DE LAQUELLE, etc.
• Préposition "à" + personne → À QUI ou AUQUEL
• Préposition "à" + chose → AUQUEL, À LAQUELLE, etc.
• Autres prépositions → LEQUEL, LAQUELLE, etc.
• Chose abstraite/neutre → QUOI

Pensez toujours à l'accord ! Les formes composées s'accordent en genre et en nombre avec l'antécédent.
