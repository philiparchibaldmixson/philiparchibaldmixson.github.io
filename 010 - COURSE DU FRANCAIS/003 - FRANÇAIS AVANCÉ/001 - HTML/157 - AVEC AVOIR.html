Règle Complexe

L'Accord du Participe Passé
avec AVOIR

La règle du COD placé avant : une exception fondamentale de la grammaire française

🥇 La Règle d'Or

Avec l'auxiliaire AVOIR, le participe passé
NE S'ACCORDE PAS avec le sujet.

Il reste INVARIABLE par défaut.

⚡ L'Exception Cruciale

Le participe passé s'accorde en GENRE et en NOMBRE
avec le COMPLÉMENT D'OBJET DIRECT (COD)
UNIQUEMENT si celui-ci est placé AVANT LE VERBE.
1

COD Après le Verbe : PAS D'ACCORD

Position naturelle du COD
Lorsque le COD est placé après le verbe (ordre normal de la phrase), le participe passé reste invariable. C'est la situation la plus courante.
J'ai mangé des pommes.
COD "des pommes" (fém. plur.) placé APRÈS → "mangé" invariable
Elle a écrit une lettre.
COD "une lettre" (fém. sing.) placé APRÈS → "écrit" invariable
Nous avons lu ces livres.
COD "ces livres" (masc. plur.) placé APRÈS → "lu" invariable
Ils ont acheté la maison.
COD "la maison" (fém. sing.) placé APRÈS → "acheté" invariable
2

COD Avant le Verbe : ACCORD OBLIGATOIRE

Pronom COD placé avant
Les pronoms COD (me, te, le, la, nous, vous, les) sont toujours placés avant le verbe. Le participe passé doit alors s'accorder avec eux.
Les pommes ? Je les ai mangées.
"les" = les pommes (fém. plur.) placé AVANT → "mangées" avec -es
Cette lettre, elle l'a écrite hier.
"l'" = la lettre (fém. sing.) placé AVANT → "écrite" avec -e
Ces livres, nous les avons lus.
"les" = les livres (masc. plur.) placé AVANT → "lus" avec -s
Ma sœur ? Je l'ai vue ce matin.
"l'" = ma sœur (fém. sing.) placé AVANT → "vue" avec -e (+ prononciation change!)
Pronom relatif « QUE » (COD)
Dans les propositions relatives, « que » peut être COD. Il représente l'antécédent placé avant, donc le participe s'accorde avec cet antécédent.
Les fleurs que j'ai achetées sont belles.
"que" = les fleurs (fém. plur.) → "achetées" avec -es
Le film que nous avons vu était génial.
"que" = le film (masc. sing.) → "vu" invariable
La voiture qu'il a vendue était rouge.
"qu'" = la voiture (fém. sing.) → "vendue" avec -e
Les exercices que tu as faits sont corrects.
"que" = les exercices (masc. plur.) → "faits" avec -s
Questions avec inversion
Dans les questions avec inversion, le COD peut être placé au début de la phrase. Le participe s'accorde alors avec lui.
Quelle robe as-tu choisie ?
"quelle robe" (fém. sing.) placé au début → "choisie" avec -e
Combien de livres avez-vous lus ?
"combien de livres" (masc. plur.) → "lus" avec -s
Quels films ont-ils vus ?
"quels films" (masc. plur.) au début → "vus" avec -s

Avant / Après : La Différence Cruciale

✗ COD APRÈS
J'ai mangé des pommes.
Le COD est après le verbe → participe invariable "mangé"
✓ COD AVANT
Je les ai mangées.
Le COD (les = les pommes) est avant → accord "mangées"
✗ COD APRÈS
Elle a écrit une lettre.
Le COD est après → participe invariable "écrit"
✓ COD AVANT
Elle l'a écrite.
Le COD (l' = la lettre, fém.) est avant → accord "écrite"

Méthode en 4 Étapes

1
Identifier l'auxiliaire
Est-ce l'auxiliaire avoir ? Si oui, continuez. Si c'est être, les règles sont différentes.
2
Chercher le COD
Posez la question "Quoi ?" ou "Qui ?" après le verbe. La réponse est le COD.
3
Localiser le COD
Le COD est-il avant ou après le verbe ? C'est la position qui détermine tout !
4
Accorder si nécessaire
Si le COD est avant → accord en genre et nombre. Si après → invariable.

Pièges à Éviter

COI ne provoque JAMAIS l'accord
Les pronoms lui, leur, y, en sont des COI (complément d'objet indirect), PAS des COD.

• "Je lui ai parlé" → "parlé" invariable (lui = COI)
• "Je leur ai téléphoné" → "téléphoné" invariable (leur = COI)
• "J'en ai mangé" → "mangé" invariable (en = COI partitif)
Verbes intransitifs (sans COD)
Certains verbes n'ont jamais de COD. Leur participe reste toujours invariable avec avoir.

• "Elles ont couru" → invariable (courir = intransitif)
• "Nous avons dormi" → invariable (dormir = intransitif)
• "Ils ont voyagé" → invariable (voyager = intransitif)
Le piège de "EN"
Avec le pronom "en", le participe reste généralement invariable, même si "en" représente un COD.

• "Des pommes ? J'en ai mangé." → "mangé" invariable
• "Des fleurs ? Il en a cueilli." → "cueilli" invariable
(Exception rare : accord possible dans un registre très littéraire)
Confusion sujet/COD
Attention à ne pas confondre le sujet avec le COD !

• "Les filles ont mangé des pommes" → "mangé" invariable
("les filles" = SUJET, pas COD. Le COD "des pommes" est après.)

• "Les pommes que les filles ont mangées" → "mangées" avec accord
("que" = les pommes = COD placé avant)

En Résumé

Avec AVOIR, règle de base :
INVARIABLE

Exception unique :
COD AVANT le verbe
→ Accord OBLIGATOIRE

COD APRÈS le verbe
→ PAS D'ACCORD
